## 結論

キーワード調査ツールは、ある語が検索エンジンで月に何回検索されているか（月間検索数）と、その関連語を調べるサービスです。
記事のテーマ選びの下調べを AI に任せる場面を想定し、6 つを「AI が API や MCP で月間検索数を取れるか」「無料でどこまで見えるか」「最小の有料額はいくらか」の 3 点で比べました。

- **登録もカードもなしで、AI に月間検索数を取らせたい** → seodata.dev。アカウントなしで REST とリモート MCP の両方が動きます
- **語数が多い、または関連語や入札額の目安まで API で取りたい** → DataForSEO。課金が語数ではなくリクエスト単位で、カード登録なしの試用クレジットで実データを取れます
- **日本語の画面で、サジェストの語の一覧を無料で見たい** → ラッコキーワード。フリーで見えるのは語の一覧までで、月間検索数と MCP は有料プランからです

## 比較の前提

- 対象に含めたもの: 公式の料金ページとドキュメントで、月間検索数の取得方法と料金を確認できる 6 つです。
  seodata.dev と DataForSEO は API と MCP が主体のデータ提供サービス、ラッコキーワード・Semrush・Ahrefs は Web 画面を持つ調査ツール、Google キーワードプランナーは Google 広告の中の機能で、成り立ちが違います
- 除外したもの: SerpApi や Brave Search API のような検索結果を返す API は、月間検索数を返さない別の種類のサービスなので外しました。
  Ubersuggest は公式の料金ページを取得できなかったため外しました
- 検証区分の意味: {{< verified run >}} = AI が実際に動かして確認した / {{< verified spec >}} = 公式ドキュメントで確認したのみ。
  ラッコキーワードで実行したのはフリーの Web 画面だけで、有料プランの MCP と API は公式の記載の確認にとどめています。DataForSEO のリモート MCP（OAuth）も実行していません
- 料金表記の注意: 通貨は各社の料金ページの表示のままで、USD と円が混ざります。Ahrefs は日本から開いたときの円建ての表示で、消費税は別です。ラッコキーワードの表示は税込です。
  ラッコキーワードの料金ページは年払いを月で割った額を既定で表示するので、表では月払いに切り替えた額で揃えました。DataForSEO は月額ではなくリクエストごとの従量です
- 月間検索数はどのツールでも推定値です。seodata.dev の規約は、数字が第三者のデータ元から集めた推定で、ほかのツールの表示と違うことがあると書いています [11]。
  同じ日に同じ語を 2 つのサービスで引いた結果は、「各対象の詳細」の seodata.dev に載せています
- 選び方の軸: 「前提条件」列は、アカウントなしで動く（seodata.dev）、アカウントと電話番号の確認で動く（DataForSEO）、支払い情報の登録が要る（Ahrefs・Google キーワードプランナー）に分かれます。
  「無料枠」列は、月間検索数そのものを無料で取れるもの（seodata.dev・DataForSEO の試用クレジット）と、無料では語の一覧や一部の機能までのもの（ラッコキーワード・Semrush・Ahrefs）に分かれます。
  「主な制約」列は、MCP や API が使えるプランの下限がツールごとに違います。「料金」列は、回数の上限が無い定額、リクエストごとの従量、月額のプランの 3 通りです
- この記事はサービスの仕様と料金の比較です。検索順位や流入が増えるかどうかは扱いません
- 検証の手順: 2026-11-10 に、seodata.dev・DataForSEO・ラッコキーワードの 3 つで行いました。
  (1) API の認証情報を非対話で渡し、残高や残り回数を記録する (2) 日本・日本語の指定で、同じ 10 語の月間検索数を取る (3) 公式の MCP サーバーにつなぎ、同じ語を MCP 経由で取る (4) 残高や残り回数を再確認する、の 4 つです。
  10 語は、この記事を配信しているサイトが扱う分野の語（`vps`・`レンタルサーバー` など）に限りました。ラッコキーワードは (1)〜(4) の対象外で、ログイン済みのフリーの画面でサジェストの語の一覧を取るところまでを行いました（フリーでは月間検索数が見えません）
- 検索結果のページそのものを取得する手段は、[スクレイピング API 5 つの無料枠比較](/posts/scraping-api-free-tier/)で比べています。
  API の認証情報を AI エージェントに渡す手段は、[シークレット管理 CLI 6 つの比較](/posts/secret-management-cli/)で比べていて、この記事の検証でもそこで扱った `op run` を使いました

## 各対象の詳細

### seodata.dev

AI エージェントから呼ぶ前提で作られた、月間検索数のデータ提供サービスです。
6 つのうち、アカウントも API キーも無しで REST と MCP の両方が動くのは seodata.dev だけです。

{{< fit run >}}
向く: 登録もカードもなしで、AI に月間検索数と類似語を取らせたい
向かない: 運営元の会社名が分かるサービスだけを使いたい。入札額の目安や月ごとの推移まで欲しい
{{< /fit >}}

- **料金体系**: Unlimited は Polar 経由のカード払いで、月ごとの契約です。データベースにまだ無い語の取得には 1 日あたりの上限（fair use）があり、超えると翌日の 0 時（UTC）まで 429 が返ると書かれています [9][11]
- **制約**: 対応する国は 50 以上で、日本（`jp`）を含みます。検索結果・被リンク・難易度・トレンドは「Coming soon」です [9]。
  データ元として、トップページは Google Ads のデータ・DataForSEO・SerpApi を挙げています [8]。
  規約・プライバシーポリシー・フッターのどこにも運営元の会社名と所在地は無く、連絡先はメールアドレスだけです [11][19]。
  調べた語は、利用者と結び付けない形で公開のキーワードページに載ることがあります [19]
- **前提条件**: REST は `GET https://api.seodata.dev/v1/keyword?q=語&country=jp` です。MCP は `https://mcp.seodata.dev/mcp`（Streamable HTTP）で、認証は なし・API キー・OAuth 2.1 の 3 通りです。
  Claude Code では `claude mcp add --transport http seodata https://mcp.seodata.dev/mcp` で登録します [9][10]。データの商用利用は規約で認められています [11]
- **検証した内容**: 公式の料金ページ・`llms.txt`・MCP の案内・規約を確認したうえで、2026-11-10 にアカウントなし・API キーなしで実行しました。

  | 操作 | 結果 |
  | --- | --- |
  | REST で 10 語（`country=jp`） | 9 語が 200。`画像 cdn` は 404（`volume` 0）。応答は `volume`・`cpc`・`competition`・`similar`・`cached` |
  | MCP の initialize と tools/list（認証なし） | サーバー `seodata.dev` 1.0.0。ツールは `lookup_keyword`・`lookup_keywords`・`get_usage` の 3 つ |
  | MCP の `lookup_keyword` と `lookup_keywords`（3 語） | REST と同じ値。どちらも 1 秒未満 |
  | MCP の `get_usage` | `plan: anonymous`、`daily.limit` 20 |

  同じ日に同じ 10 語を DataForSEO（Google Ads）でも引くと、値が一致したのは 3 語でした。

  | 語 | DataForSEO | seodata.dev |
  | --- | --- | --- |
  | vps | 12,100 | 12,100 |
  | ドメイン 取得 | 12,100 | 12,100 |
  | url 短縮 | 110,000 | 110,000 |
  | レンタルサーバー | 8,100 | 9,900 |
  | メール配信 | 880 | 1,000 |
  | パスワード管理 | 40,500 | 60,500 |
  | アクセス解析 | 1,000 | 1,900 |
  | 死活監視 | 1,300 | 1,900 |
  | ログ管理 | 320 | 480 |
  | 画像 cdn | 50 | データなし |

  食い違った 6 語は、すべて seodata.dev のほうが大きい値でした。原因は確認していません。
  `get_usage` の使用回数は 14 語を引いたあとで 5 と表示され、公式の「1 語で 1 回」という数え方と合いませんでした。そのため、1 日の上限を超えたときの応答は確かめていません

### DataForSEO

検索や広告のデータを API で提供するサービスで、Google Ads（キーワードプランナー）のデータを REST で取れます。
月額のプランは無く、リクエストごとの従量です。

{{< fit run >}}
向く: 多くの語をまとめて引きたい。関連語や入札額の目安、月ごとの推移まで API で取りたい
向かない: 入金なしで使い続けたい（試用クレジットは一回きりで、その先は最低入金から）
{{< /fit >}}

- **料金体系**: Google Ads の endpoint は、検索数も関連語も同じ単価です。Standard は POST のあとに結果を取りに行く方式で、料金ページの目安は 1〜3 時間、Live は 1 回の POST で結果が返ります [1]。
  同社の Keywords Data API の一覧ページには別の単価が載っていますが、実行時に引かれた額は Google Ads の料金ページの単価と同じでした
- **制約**: 登録直後は、残高の照会だけが通ります。データの endpoint は、無料のもの（対応言語の一覧）でも 403 と `40104 Please verify your account before using the API` が返り、電話番号の確認が済むと通りました。
  公式の MCP サーバーのツールは 4 つで、API のドキュメントを引く `docs_index`・`docs_list_sections`・`docs_search` と、任意の endpoint を呼ぶ `api_request` です。endpoint ごとのツールは無く、AI がドキュメントを引いてからリクエストを組み立てます [7]。
  `api_request` は既定で AI 向けの経路（`.ai`）を呼び、通常の経路に戻すには `noAiMode` を指定します [7]。検証では、既定の応答に `cost` と残高が含まれませんでした
- **前提条件**: 登録画面は Personal email と Business email の 2 択で、Personal は電話番号の確認が入ります。認証は API 用の login と password による Basic 認証です。
  MCP は、リモートの `https://mcp.dataforseo.com/v3/mcp`（既定は OAuth 2.0 で、Basic 認証のヘッダーも使える）と、`npx dataforseo-mcp-server` をローカルで起動する方式（環境変数 `DATAFORSEO_LOGIN` と `DATAFORSEO_PASSWORD`）の 2 経路です [6][7]。
  ローカル起動に要る Node.js の版は、MCP のページが 18 以上と書いています [6]。README の 20 以上はリポジトリを開発するときの要件で、起動の手順には版の記載がありません [7]。
  入金はクレジットカードか PayPal です
- **検証した内容**: 公式の料金ページ・ドキュメント・MCP サーバーの README を確認したうえで、2026-11-10 に試用クレジットだけで実行しました。入金はしていません。地域と言語は `location_code: 2392`（Japan）と `language_code: "ja"` です。

  | 操作 | 結果 |
  | --- | --- |
  | `GET /v3/appendix/user_data` | 200。残高 USD 1 |
  | 検索数の Live（1 語） | 200（1.1 秒）。`cost` 0.09 |
  | 検索数の Live（10 語） | 200（10.7 秒）。`cost` 0.09。1 語のときと同じ額 |
  | 検索数の Standard（10 語） | `cost` 0.06。投入から約 1 分で完了し、Live と同じ値 |
  | MCP（ローカル起動、サーバー 3.1.3）で検索数の Live（3 語） | 200（7.5 秒）。REST と同じ値。応答に `cost` は無い |
  | MCP で関連語（`keywords_for_keywords` の Live、`vps`） | 200（5.0 秒）。10 件 |
  | 残高の再確認 | USD 0.58（0.09 × 4 と 0.06 × 1 を消費） |

  応答の項目は、月間検索数・競合性（LOW / MEDIUM / HIGH と 0〜100 の指数）・ページ上部掲載の入札額の下限と上限・CPC・12 か月ぶんの月ごとの検索数です。
  Standard が約 1 分で完了したのは今回の 1 回の観測で、料金ページの目安より短い結果でした。確認の直後に 1 回だけ、結果の取得が `40104` で返り、再試行で通りました。
  関連語が 10 件だったのが AI 向けの応答による絞り込みかどうかは、確かめていません

### ラッコキーワード

日本語の画面で、サジェスト・関連語・月間検索数・競合サイトの調査を行う国内のツールです。
MCP は有料プランの機能で、料金ページと AI 連携ガイドが、プランごとの消費の倍率を公開しています。

{{< fit run >}}
向く: 日本語の画面で、サジェストの語の一覧を無料で見たい。月額の有料プランで MCP を使いたい
向かない: 無料のまま月間検索数を見たい。少ないクレジットで AI から多く呼びたい
{{< /fit >}}

- **料金体系**: 年払いにすると、月払いの 12 か月ぶんの半額です。契約は前払いで、自動更新は任意です [12]
- **制約**: 割り当てのクレジットは、プランが上がるほど多く、AI 経由の倍率は低くなります。フリーのクレジットの有効期限は 1 週間です [12]。
  一括キーワード調査は、画面の記載では 1 リクエストあたりの最低消費が決まっています。AI 経由の倍率がこの最低消費にも掛かるかは、確かめていません
- **前提条件**: MCP の接続先は `https://api.rakkokeyword.com/mcp` で、エントリー以上の有料プランで使えます [13]
- **検証した内容**: 公式の料金ページと AI 連携ガイドを確認したうえで、2026-11-10 にフリーのアカウントの Web 画面で実行しました。有料プランの MCP と API は実行していません。

  | 操作 | 結果 |
  | --- | --- |
  | サジェストキーワード（Google）で `vps` | 1,006 件の語の一覧が出る。月間検索数・SEO 難易度・CPC・競合性の列は「月間検索数は有料プランでご覧いただけます」の案内で覆われ、数字は出ない |
  | 一括キーワード調査の画面 | 「有料プランからご利用可能」。結果の欄はサンプル表示で、操作できない |
  | 契約管理の画面 | プランは「フリー」。クレジットの残りは 49 / 50（サジェストの 1 回で 1 消費）。次の付与は翌週の月曜 0 時 |

  フリーで確かめられるのは、どんな語が一緒に検索されているかの一覧までです

### Semrush

キーワード・競合サイト・被リンク・順位をまとめて調べる海外の SEO ツールです。
無料の Free と有料プランがあり、MCP と API は有料側の機能です。

{{< fit spec >}}
向く: 被リンクや順位の調査まで 1 つの有料ツールにまとめ、そのデータを MCP で AI に渡したい
向かない: 月間検索数の下調べだけを、低い月額で AI に任せたい
{{< /fit >}}

- **料金体系**: 有料プランは SEO・Starter・Pro+ の 3 段と、個別見積りの Advanced です。年払いの月換算は月払いより低くなります [14]
- **制約**: MCP の FAQ は、対象を有料の Semrush One・SEO Classic・Trends API の契約とし、無料では使えないと書いています。料金ページのプランの一覧で「MCP access」があるのは Starter からで、最小の SEO の一覧にはありません [14][15]
- **前提条件**: 表の「前提条件」列のとおりです [14]
- **検証した内容**: 公式の料金ページと MCP のページの FAQ を確認しました。アカウントは作っておらず、Free の画面も実行していません

### Ahrefs

被リンクの調査から始まった海外の SEO ツールで、キーワードの調査（Keywords Explorer）や順位の追跡も持ちます。
API と MCP は、料金ページのプランの一覧に含まれています。

{{< fit spec >}}
向く: 被リンクや競合サイトの調査を主に使い、同じ契約の API や MCP で AI からも引きたい
向かない: 無料のトライアルで確かめてから決めたい。月間検索数の下調べだけに使いたい
{{< /fit >}}

- **料金体系**: プランは Starter・Lite・Standard・Advanced と、個別見積りの Enterprise です。年払いの割引があり、料金ページの FAQ は値引きを行わないと書いています [16]
- **制約**: 1 リクエストの最大行数と、利用者 1 人あたりのクレジットは、プランごとに決まっています [16]
- **前提条件**: 表の「前提条件」列のとおりです [16]
- **検証した内容**: 公式の料金ページを日本から開いて確認しました。契約はしておらず、API と MCP は実行していません

### Google キーワードプランナー

Google 広告の中にある、キーワードの候補と月間検索数の見積りを調べる機能です。
DataForSEO の Google Ads の endpoint が返すのは、このキーワードプランナーのデータです [1]。

{{< fit spec >}}
向く: Google 広告のアカウントと支払い情報が既にあり、画面で調べられれば足りる
向かない: 支払い情報を登録せずに調べたい。個人の小さなプロジェクトから API で取りたい
{{< /fit >}}

- **料金体系**: ヘルプは、「新しいキーワードの候補を取得する」などの基本機能を使うには、支払い情報を入力してアカウント設定を完了する必要があると書いています [17]
- **制約**: Google Ads API のアクセスレベルは Test・Explorer・Basic・Standard の 4 段です。キーワードの計画に使うサービスは Explorer では制限され、使うには Basic 以上の申請が要ります [18]
- **前提条件**: 表の「前提条件」列のとおりです [17][18]
- **検証した内容**: 公式のヘルプと Google Ads API のドキュメントを確認しました。支払い情報の登録が要るため、実行はしていません

{{< svg src="keyword-research-flow.svg" alt="用途別の判断フロー。登録もカードもなしで AI に月間検索数を取らせたいなら seodata.dev、語数が多く関連語や入札額の目安まで API で取りたいなら DataForSEO、日本語の画面で調べ MCP は有料プランでよいならラッコキーワード、被リンクや順位まで 1 つの有料ツールにまとめたいなら Semrush か Ahrefs、Google 広告のアカウントと支払い情報が既にあるなら Google キーワードプランナー" caption="図: 用途別の判断フロー" >}}

- 登録もカードもなしで、AI に月間検索数を取らせたい → seodata.dev。決め手は「前提条件」列と「無料枠」列です。
  運営元の会社名が規約に無い点は、「主な制約」列で確かめてください
- 語数が多い。関連語や入札額の目安まで API で取りたい → DataForSEO。決め手は「料金」列と「無料枠」列です。
  試用クレジットを使い切ったあとは、最低入金からの従量になります
- 日本語の画面で調べたい。MCP は有料プランでよい → ラッコキーワード。決め手は「無料枠」列と「主な制約」列です。
  下位のプランほど AI 経由の消費の倍率が高いので、MCP で多く呼ぶなら倍率も見て選ぶことになります
- 被リンクや順位の調査まで、1 つの有料ツールにまとめたい → Semrush か Ahrefs。決め手は「料金」列と「主な制約」列です。
  どちらも、月間検索数の下調べだけが目的なら月額がほかの対象より大きくなります
- Google 広告のアカウントと支払い情報が既にある → Google キーワードプランナー。決め手は「前提条件」列です。
  API で取るには、アクセスレベルの申請が別に要ります

## よくある質問

### 月間検索数は無料で調べられますか？

seodata.dev は、アカウントなしで 1 日 20 回まで月間検索数を返します [8][9]。DataForSEO は、登録時の試用クレジットの範囲でカード登録なしに取れます [2][3]。
ラッコキーワードのフリーは語の一覧までで、月間検索数は有料プランからです [12]。

### Claude などの AI から月間検索数を取るには何が要りますか？

seodata.dev はリモート MCP の URL を登録するだけで、サインインなしで動きます [10]。
DataForSEO は公式の MCP サーバーがあり、リモートは OAuth か Basic 認証、ローカルは API の login と password で認証します [6][7]。
ラッコキーワードの MCP はエントリー以上、Ahrefs の MCP は Lite 以上の有料プランが要ります [13][16]。

### ツールによって月間検索数が違うことはありますか？

あります。同じ日に同じ 10 語を DataForSEO と seodata.dev で引いた結果は、一致が 3 語、食い違いが 6 語、片方にデータが無い語が 1 語でした。
seodata.dev の規約は、数字が推定で、ほかのツールの表示と違うことがあると書いています [11]。

### クレジットカードの登録は要りますか？

seodata.dev の無料の範囲と、DataForSEO の試用クレジット、ラッコキーワードのフリー、Semrush の Free は、カードの登録なしで始められます [2][8][12][14]。
Google キーワードプランナーは支払い情報の登録が要ります [17]。
