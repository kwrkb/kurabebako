## 結論

ドメインレジストラは、独自ドメインを登録して年ごとに更新する窓口です。
AI にドメインの空き確認から取得、DNS の設定まで任せたい人向けに、国内 4 社と海外 2 社を、
取得費と更新費の差、Whois 代行の費用、API や CLI・MCP で空き確認と取得ができるかの 3 点で比べました。

- **.jp も含めて国内で、取得後の DNS や Whois の管理まで CLI に任せたい** → スタードメイン。「前提条件」列の CLI と MCP が公式に用意され、「無料枠」列のとおり Whois 代行に追加費用がかかりません

## 比較の前提

- 対象に含めたもの: 個人が公式サイトから申し込め、.com の取得費と更新費が公式の料金ページに載っているレジストラのうち、国内で AI から操作できる公式の経路（API・CLI・MCP）を持つ 3 社（スタードメイン・XServer ドメイン・ムームードメイン）、
  国内で利用者の多いお名前.com、海外で原価販売の Cloudflare Registrar、海外で API の公開が詳しい Porkbun の 6 社です
- 除外したもの: Namecheap は本番の API に利用条件があり、条件の中身が公式ページに書かれていないため外しました。
  DNS のクエリに答えるだけのサービス（DNS ホスティング）は「名前を買う先」ではないので対象外です。
  レンタルサーバーとの同時契約で取得・更新が永久無料になる仕組みは、[国内の共用レンタルサーバー比較](/posts/shared-hosting-japan/)で扱っています
- 検証区分の意味: {{< verified run >}} = AI が実際に動かして確認した / {{< verified spec >}} = 公式ドキュメントで確認したのみ
- 料金表記の注意: 国内 4 社は税込の円で、1 年あたりの価格です。ムームードメインとお名前.com は、料金ページを開いた時点の表示がサービス維持調整費を含まない額です。この表には、ページ上の「サービス維持調整費を含む」にチェックを入れた額を載せています。
  お名前.com の更新費は登録時期で変わるため「〜」付きのままです。
  Cloudflare Registrar の価格は API の空き確認が返した USD の値で、公開ページには具体額がありません。Porkbun は料金ページの USD です。
  初年度だけ安い TLD が多いので、取得費だけでは並べず、2 年目以降の更新費を棒グラフにしています
- 選び方の軸: 「料金」列は、取得費と更新費の差で分かれます。差が無いのは海外 2 社で、国内 4 社は初年度が安く 2 年目から上がります。
  「無料枠」列は、Whois 代行が無料で付くか、初年度の取得が無料になる条件があるかで分かれます。
  「主な制約」列は、AI に任せるときの壁で分かれます。空き確認の API に注文の権限が要るか、Web の検索結果に更新費まで出るか、.jp を扱うかです。
  「前提条件」列は、API を使い始めるまでに何が要るかで分かれます。契約・前払い・カード登録・アカウントだけ、の違いです
- 検証の手順: スタードメインは 2026-11-01 に、検証用のドメインを 1 つ取得して Star8 アカウントの API キーを発行し、読み取り専用のキーで Star8 CLI の参照コマンドを流しました。
  取得したドメインは自動更新を切り、記事のためだけに保持しています。Cloudflare Registrar は同日に、Registrar の読み取り権限だけのトークンで検索・空き確認・保有一覧の API を流しました。
  3 社の Web の検索フォームも同日にブラウザで操作し、空きと価格の表示を料金ページと照合しました。
  Porkbun は 2026-11-06 に、別の用途で取得してあった .net のドメインに対して、購入の権限が無い API キーで料金・空き確認・保有ドメインの参照・DNS レコードの作成と削除を流しました。
  ムームードメインは 2026-11-10 に、カードを登録していないアカウントで公式の MCP サーバーに接続し、保有一覧・空き確認・見積のツールを呼びました。購入のツールは呼んでいません。
  記事のために新しく買ったのは、スタードメインの検証用の 1 件だけです。
  API に渡すキーは [シークレット管理 CLI 6 つの比較](/posts/secret-management-cli/)で扱った `op run` で注入し、本番のゾーンや DNS には権限を付けていません

## 各対象の詳細

### スタードメイン

エックスサーバー社のドメイン取得サービスで、サーバーとは別に単体で契約できます。
公式の CLI と MCP サーバーがあり、取得後のネームサーバー・DNS・Whois・レジストラロックまで同じ鍵で操作できます。

{{< fit run >}}
向く: .jp も含めて国内で取得し、取得後の DNS や Whois の管理まで CLI や MCP に任せたい
向かない: 空き確認や取得の API を前払いなしで使いたい、または契約前に API を試したい
{{< /fit >}}

- **料金体系**: 移管は 1 年の更新を含む価格で、更新費と同じ額です。料金ページの価格は 1 年目の新規取得に適用され、2 年目以降は更新価格に切り替わります。.co.jp などの属性型 JP とプレミアムドメインは API では取得・移管できません [1][3]
- **制約**: 空き確認・価格確認・新規取得・移管・更新の API は、キーに「新規取得・移管・更新（お申し込み）を許可する」が付いていないと FORBIDDEN になります。この権限を付ける条件は、Whois 初期値の登録と前払い残高です [3][4]。
  実際の注文は CLI でも対話端末での確認文字列の入力が要り、CI などの非対話環境からは申し込めません [4]。
  取得直後のドメインはレジストラロックと指定事業者ロックが有効で、申し込み画面の注記どおり解除もできない状態で返りました。Web の検索結果は 1 年目の価格だけで、更新価格は料金ページを別に開く必要があります
- **前提条件**: API キーは Star8 アカウントの「APIキー管理」で発行し、読み取り専用・カスタム・対象ドメインの限定・IP 制限を選べます [3]。
  この検証では、契約が無い状態のアカウントに「APIキー管理」が表示されず、ドメインを 1 つ取得した後に表示されました。マニュアルには契約の条件は書かれていません。
  CLI は Node.js 18 以上で `npm install -g star8-cli`、キーは環境変数 `STAR8_API_KEY` か `star8 auth login` で渡します [4]
- **検証した内容**: 2026-11-01 に、取得したドメインに対して読み取り専用の API キーで Star8 CLI 1.6.1 を流しました。Web の検索フォームも同日にブラウザで操作しました。

  | 手順 | コマンド | 結果 |
  | --- | --- | --- |
  | 保有一覧 | `star8 --format json domain list` | 200。取得したドメインが `status: active` で返る |
  | 詳細 | `domain show <ドメイン>` | 200。`auto_renew: false`（画面で切った自動更新が反映）、`epp_statuses` に `clientTransferProhibited` |
  | ネームサーバー | `domain nameservers show <ドメイン>` | 200。`ns1〜ns3.star-domain.jp`（申し込み時に NS 設定を選ばなくても入る） |
  | DNS | `domain dns list <ドメイン>` | 200。`records: []` |
  | Whois | `domain whois show <ドメイン>` | 200。`whois_privacy: true`（代理公開は既定で有効）。登録者の欄も返るので出力は公開しない |
  | ロック | `domain registrar-lock show <ドメイン>` | 200。`locked: true`、`unlock_blocked: true` |
  | 価格表 | `domain pricing --tld com,net,jp` | **FORBIDDEN**「このAPIキーでは、ドメインの取得可能性・価格確認・新規取得・移管・契約更新が許可されていません」 |
  | 空き確認 | `domain check <候補>` | 同じ FORBIDDEN。`register --dry-run` も同じ |
  | Web の検索 | トップの検索欄に候補名 → 検索 | ログインも CAPTCHA も無しで結果が出る。「取得可能です」と 1 年目の価格（.com・.net・.org・.jp）。更新価格は出ない |

### Cloudflare Registrar

CDN と DNS の Cloudflare が、レジストリと ICANN の料金に上乗せせずドメインを販売する窓口です。
対象は Cloudflare の DNS を使うドメインに限られ、取得した名前は登録中ずっと Cloudflare のネームサーバーで運用します。

{{< fit run >}}
向く: .com や .net を原価で買い、空き確認から取得まで API だけで済ませたい
向かない: .jp を取りたい、または更新や移管まで API で自動化したい
{{< /fit >}}

- **料金体系**: FAQ は「registry and ICANN list price with no markup」と書き、公開ページに TLD ごとの具体額はありません。価格は管理画面か API の空き確認で返ります。
  移管時に加算される年数も原価で、.uk と .nz のような一部の ccTLD は移管で年数が増えません [6][10]
- **制約**: 対応 TLD の一覧に .jp はなく、API の空き確認も .jp に `extension_not_supported` を返しました [7][9]。
  API ガイドは「first beta release」で、更新・移管・連絡先の変更は「not yet available」です。API リファレンスには移管の項目が載っており、公式内で記述が分かれます [8]。
  API からの登録は成功後に返金できず、自動更新の既定は API では無効、管理画面では有効と経路で逆になっています [8][23]。
  検索 API の結果はキャッシュで、派生した名前が混じるため、公式も登録前に空き確認 API で確かめるよう案内しています [8]
- **前提条件**: API ガイドは Registrar の書き込み権限のトークンを前提に書いていますが、検索・空き確認・保有一覧は読み取り権限だけで通りました [8]。
  登録には管理画面で設定した支払い方法が要り、1 回の空き確認で送れるドメインの数に上限があります [9]
- **検証した内容**: 2026-11-01 に、Registrar の読み取り権限だけを付けた API トークンで実行しました。本番のゾーンや DNS の権限は付けていません。

  | 手順 | 呼び出し | 結果 |
  | --- | --- | --- |
  | トークンの確認 | `GET /user/tokens/verify` | 200、`status: active` |
  | 候補の検索 | `GET /accounts/{id}/registrar/domain-search?q=<候補>&extensions=com&extensions=net&limit=5` | 200。返ったのはすべて .net で、派生した名前が混じる |
  | 空き確認 | `POST /accounts/{id}/registrar/domain-check`（.com / .net / .jp / 保有中の名前） | 200。.com と .net は `registrable: true` で `registration_cost` と `renewal_cost` が同額。.jp は `extension_not_supported`。保有中の名前は `domain_unavailable` |
  | 保有一覧 | `GET /accounts/{id}/registrar/domains` | 200。保有中の 1 件が返る |

### XServer ドメイン

エックスサーバー社のもう 1 つのドメイン取得サービスで、レンタルサーバーのエックスサーバーと同じアカウントで契約します。
API・CLI・MCP はスタードメインと同じ構成で、エンドポイント・権限の条件・上限が揃っています。

{{< fit spec >}}
向く: 初年度の費用を抑えて 1 個目を取り、検索結果の段階で更新費まで確かめたい
向かない: 過去に契約や永久無料特典の利用がある、または契約前に API を試したい
{{< /fit >}}

- **料金体系**: はじめての方の 0 円は 1 年目の取得だけに適用され、2 年目からは更新価格です。対象は過去に XServer ドメインの契約が無く、エックスサーバーの永久無料特典を使っておらず、移管申請中のドメインが無い人です [11]。
  料金ページには Whois 代行の価格の記載が無く、サービストップに「Whois代行機能なども標準提供」とあります [11][12]
- **制約**: 空き確認と価格の API にも「新規取得・移管・更新を許可する」が要り、その条件はスタードメインと同じ前払い残高と Whois 初期値です。取得の API は対象ドメインを限定したキーでは使えず、キーをすべてのドメインに向ける必要があります [13][15]。
  MCP サーバーでは取得・移管・更新が既定で無効で、環境変数で明示的に有効にしたうえで、要求ごとに税込総額の承認が要ります [14]。
  Web の検索結果には取得価格と翌年以降の更新価格が並び、ログインしていない閲覧者にもはじめての方の価格で表示されます。適用の可否は申し込み時の判定です
- **前提条件**: API キーは XServer アカウントの「APIキー管理」で発行します。この検証では、ドメインの契約が無いアカウントに「APIキー管理」が表示されませんでした。
  0 円の取得を API から行うにはカードの登録が要り、無いと `CREDIT_CARD_REQUIRED` が返ります [13][15]
- **検証した内容**: API は契約が要るため実行していません。2026-11-01 に、Web の検索フォームをブラウザで操作し、ログインも CAPTCHA も無しで候補の空きと価格（取得と翌年以降の更新）が料金ページと一致することを確認しました。
  公式の API リファレンス・MCP のマニュアル・料金ページは同日に確認しています

### ムームードメイン

GMO ペパボのドメイン取得サービスで、公式のリモート MCP サーバーを公開しています。
AI クライアントからは OAuth で接続し、候補の検索から見積、購入、DNS の操作まで 1 つの接続で扱えます。

{{< fit run >}}
向く: 前払いなしで、AI クライアントから MCP だけで空き確認と見積まで進めたい
向かない: .jp の見積と購入まで MCP で進めたい、または Web の検索結果の段階で更新費まで確かめたい

- **料金体系**: 価格は 1 年あたりで、.jp は 1 年契約だけ選べます。料金ページと Web の検索結果には「サービス維持調整費を含む」のチェックボックスがあり、開いた時点では外れています。
  外れた状態の額は調整費を含みません。MCP の検索と見積は、ドメイン代・調整費・税の内訳つきで、チェックを入れた額と同じ合計を返しました。

- **制約**: 2026-10-24 から止まっていた新規ユーザー登録・一部 TLD の新規取得・API からの新規取得は、2026-11-05 に再開しました。ムームーメールとムームーサーバーの新規申し込みは停止が続き、再開の時期は公式に未定です [18]。

### お名前.com

GMO インターネットのドメイン取得サービスで、国内レジストラのシェアでは最大手です。
個人向けの API は無く、AI に任せるならブラウザ操作の範囲になります。

{{< fit spec >}}
向く: 1 円の対象 TLD を 1 個だけ取り、Whois 代行も同時に無料で付けたい
向かない: API や CLI で取得や管理を自動化したい、または更新費を事前に確定させたい
{{< /fit >}}

- **料金体系**: 1 円の価格は 1 人 1 個までで、2 個目以降と過去に 1 円で取得した人には通常の割引価格が適用されます。更新費は「〜」付きで、登録時期により異なる旨の注記があります。
  レンタルサーバーとの同時契約では対象 TLD の更新費が無料になり、12 か月以内にサーバーを解約すると実費が請求されます [19]
- **制約**: Whois 情報公開代行は新規取得と同時なら無料で、後から付けると年額がかかります。メール転送オプションは別料金です [20]。
  料金一覧の「サービス維持調整費含む」はチェックボックスで、開いた時点では外れています。比較表の更新費はチェックを入れた額です。
  Whois 代行を付けられるかは TLD ごとに料金一覧の「Whois代行」列で分かれます [19][20]
- **前提条件**: API 連携は「販売パートナー制度」の案内にだけ載っており、個人の利用者向けの API は公開されていません [19]
- **検証した内容**: アカウントを作らず、実行していません。2026-11-01 にブラウザで料金一覧と Whois 情報公開代行のページを確認しました。
  料金一覧は 2026-11-10 に開き直し、チェックの有無で更新費と移管費の表示が変わることを確認しています

### Porkbun

米国のレジストラで、.com を取得・更新・移管とも同じ価格で販売し、API の仕様を詳しく公開しています。
.jp は扱わないため、国内向けのサイトでは .com や .net が対象になります。

{{< fit run >}}
向く: 取得と更新を同じ価格で買い、購入できない鍵のまま空き確認から DNS の操作まで API で済ませたい
向かない: .jp を取りたい、または USD 以外で支払いたい
{{< /fit >}}

- **料金体系**: 料金ページは ICANN などの手数料を含んだ USD の価格で、.com は取得・更新・移管が同額です。初年度だけ安い TLD には「1st Yr Sale!」の印が付きます。.jp は扱わず、.jp.net と .jpn.com は別の TLD として載っています [21]。
  料金の API は認証なしで呼べ、料金ページと同じ値を返しました [24]
- **制約**: 空き確認の API は 1 回に送れる件数と、単体・一括それぞれの頻度に上限があります。購入の API は前払いクレジットから支払い、アカウントごとの月の購入上限と 1 注文の上限が既定で決まっています [22]。
  一括の空き確認に .jp を混ぜると、その 1 件だけが `invalid` に `INVALID_TLD` で入り、残りの名前には答えが返りました。
  DNS の書き込みは、ネームサーバーが Porkbun 以外を向いていても成功扱いで保存され、外からの名前解決には効かないことを `warnings` で知らせる仕様です [25]
- **前提条件**: API キーは読み取り・購入・ドメイン管理・DNS などの権限別に発行し、管理画面には「読み取り専用」と「購入以外を管理」のプリセットがあります。鍵に付いた権限は `/ping` の `scopes` で確かめられます [24]。
  登録・更新・移管にはアカウントのメールと電話の確認が要ります [22]
- **検証した内容**: 2026-11-06 に、別の用途で取得してあった .net のドメインに対して、「購入以外を管理」のプリセットで発行した API キー（購入と入金の権限なし）で実行しました。

  | 手順 | 呼び出し | 結果 |
  | --- | --- | --- |
  | 鍵の確認 | `GET /ping` | 200、`credentialsValid: true`。`scopes` に `purchase` と `funding` が無い |
  | 料金 | `GET /pricing/get?tlds=com,net,jp,xyz`（認証なし） | 200。.com と .net は取得・更新・移管が同額で、料金ページと一致。.jp は `unsupported` |
  | 保有一覧 | `POST /domain/listAll` | 200。購入直後の既定で `autoRenew`・`whoisPrivacy`・`apiAccess`・`securityLock` がすべて有効 |
  | 空き確認 | `POST /domain/checkDomain`（.com / .net / .jp / 保有中の名前を一括） | 200。.com と .net は `avail: yes` で料金表と同額。保有中の名前は `avail: no`。.jp は `invalid` に `INVALID_TLD` |
  | ネームサーバー | `GET /domain/getNs/<ドメイン>` | 200。Porkbun のネームサーバー 4 台 |
  | DNS の一覧 | `GET /dns/retrieve/<ドメイン>` | 200。メール転送の MX と SPF の TXT が購入時から入っている |
  | DNS の作成と削除 | `POST /dns/create/<ドメイン>` → `POST /dns/delete/<ドメイン>/<id>` | どちらも 200。作った TXT は 11 秒後に外部の DNS リゾルバーから引け、削除後は一覧から消えた |

## 用途別の選び方

最初に分かれるのは、.jp を取るかどうかです。「主な制約」列のとおり、海外 2 社は .jp を扱いません。
国内で取るなら、取得後の管理まで AI に任せるか、初年度の費用を抑えるか、前払いなしで MCP から進めたいかで分かれます。

{{< svg src="domain-registrar-flow.svg" alt="用途別の判断フロー。.jp も含めて国内で取得後の DNS や Whois の管理まで CLI に任せたいならスタードメイン、.com や .net を原価で買い空き確認から取得まで API だけで済ませたいなら Cloudflare Registrar、初年度の費用を抑えて 1 個目を取り更新費も検索結果で確かめたいなら XServer ドメイン、前払いなしで AI クライアントから MCP だけで空き確認と見積まで進めたいならムームードメイン、サーバーとセットで永久無料のドメインを使うならレジストラ単体ではなく共用サーバー" caption="図: 用途別の判断フロー" >}}

- .jp も含めて国内で、取得後の DNS や Whois の管理まで CLI に任せたい → スタードメイン。決め手は「前提条件」列の公式 CLI と MCP で、Whois 代行は「無料枠」列にあります。空き確認の API に注文の権限が要る点は「主な制約」列です
- .com や .net を原価で買い、空き確認から取得まで API だけで済ませたい → Cloudflare Registrar。決め手は「料金」列の取得と更新が同額な点で、.jp を扱わない点と更新・移管が API 未対応な点は「主な制約」列です
- 初年度の費用を抑えて 1 個目を取り、更新費も先に確かめたい → XServer ドメイン。決め手は「無料枠」列のはじめての方の取得と、「主な制約」列の検索結果に更新費が並ぶ点です
- 前払いなしで、AI クライアントから MCP だけで空き確認と見積まで進めたい → ムームードメイン。決め手は「前提条件」列の、アカウントだけで接続できる公式 MCP です。.jp は見積に進めない点と、Web の検索結果に更新費が出ない点は「主な制約」列です
- サーバーとセットで永久無料のドメインを使いたい → レジストラ単体ではなく、[国内の共用レンタルサーバー比較](/posts/shared-hosting-japan/)が対象です

提携のある国内 3 社の順位は本文の比較結果で決めています。Cloudflare Registrar・お名前.com・Porkbun は提携が無いためここには載せていません。

{{< ranking >}}
star-domain: 公式の CLI と MCP で取得後のネームサーバー・DNS・Whois・ロックまで操作でき、Whois 代行が無料で付きます。この記事で読み取り専用の API キーから参照コマンドを実際に流しました
xserver-domain: API・CLI・MCP はスタードメインと同じ構成で、はじめての方は 1 個目の取得が 0 円です。Web の検索結果に更新費まで並ぶ唯一の対象で、.com の更新費は国内 4 社で 2 番目に低い値です
muumuu-domain: 公式のリモート MCP がアカウントだけで接続でき、この記事では前払いもカード登録もなしで空き確認と .com の見積まで実行しました。.jp は MCP では見積に進めず、.com と .jp の更新費は提携のある 3 社で最も高い値です
{{< /ranking >}}

## よくある質問

### ドメインの取得や更新は API から自動化できますか？

公式の経路があるのは、6 社のうちスタードメイン・XServer ドメイン・ムームードメイン・Cloudflare Registrar・Porkbun の 5 社です [3][13][17][8][22]。
ただし自動化の範囲は分かれます。Cloudflare Registrar の API は beta で取得までに限られ、更新と移管は未対応です [8]。
エックスサーバー系の 2 社は、空き確認の API にも注文の権限が要り、実際の注文は対話端末での確認が必須です [4][13]。

### Whois 代理公開（Whois 情報公開代行）は無料ですか？

スタードメイン・Cloudflare Registrar・Porkbun は無料で付き、XServer ドメインは標準提供と案内しています [5][10][21][12]。
お名前.com は新規取得と同時に申し込めば無料で、後から付けると年額がかかります [20]。
ムームードメインは料金ページに Whois 代理公開の記載がありません [16]。
