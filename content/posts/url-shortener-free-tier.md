## 結論

短縮リンクサービスは、長い URL を短い URL に置き換えて配り、そのクリック数を数えるサービスです。
無料プランを持つ 4 つを、「無料枠を何の単位で数えるか」「消したリンクの枠が戻るか」「無料のまま独自ドメインと API を使えるか」の 3 点で比べました。

- **作って消すを繰り返す。API で作成から削除までを自動化したい** → Short.io。枠は同時に持てる本数で数え、消せば戻ります
- **独自ドメインを無料で複数載せたい。月に作る本数は少なくてよい** → Dub。「無料枠」列の独自ドメインが最も多く、既定のドメインを使わずに済みます
- **独自ドメインを 1 つだけ無料で載せ、月に数本で足りる** → Rebrandly。「無料枠」列に独自ドメインが 1 つ含まれます

| こういう条件なら | 対象 | 決め手 |
| --- | --- | --- |
| 作って消すを繰り返す。API で作成から削除までを自動化したい | Short.io | 「無料枠」列（同時に持てる本数で数える）と「検証区分」列（削除まで一巡） |
| 独自ドメインを無料で複数載せたい。月に作る本数は少なくてよい | Dub | 「無料枠」列（独自ドメインの数）と「主な制約」列（消しても枠は戻らない） |
| 独自ドメインを 1 つだけ無料で載せ、月に数本で足りる | Rebrandly | 「無料枠」列（独自ドメイン 1 つ）と「主な制約」列（消しても枠は戻らない） |
| アカウントだけで月に数本。広告つきの中間ページを許容できる | Bitly | 「主な制約」列（中間ページ、独自ドメイン無し） |

クリックの計測そのものが目的で、サイト全体の訪問を数えたいなら、[アクセス解析の無料枠比較](/posts/analytics-free-tier/)が対象です。

## 比較の前提

- 対象に含めたもの: 公式の料金ページに無料プランの上限が載っていて、独自ドメインと API の扱いが読み取れる 4 つです。Short.io と Dub は API で一巡を実行し、Bitly と Rebrandly は公式ページの確認にとどめています
- 除外したもの: 自分のサーバーで動かすオープンソースの短縮リンク（YOURLS など）は、無料枠の比較にならないので対象外です。サイト全体の訪問数を数えるアクセス解析は、[アクセス解析の無料枠比較](/posts/analytics-free-tier/)で比べています
- 検証区分の意味: {{< verified run >}} = AI が実際に動かして確認した / {{< verified spec >}} = 公式ドキュメントで確認したのみ
- 料金表記の注意: 通貨は USD で、税の扱いは各社の料金ページの表示のままです。Bitly の Core は年払いしか無く、月額は年額を 12 で割った表示です [12]。
  Rebrandly の料金ページは年払いの月あたり額を先に出し、月払いの額は切り替えで出ます。表には月払いの額を載せ、年払いを括弧で補いました [17]
- 選び方の軸: 「無料枠」列は、数える単位で分かれます。
  Short.io は同時に持てる本数、ほかの 3 社は月の新規作成数で数え、月の枠は翌期に繰り越しません。
  「主な制約」列は、消したリンクの枠が戻るか、独自ドメインを無料で載せられるか、転送のときに中間ページを挟むかで分かれます。
  「前提条件」列は、無料ドメインを使うときに電話番号の検証が要るか（Short.io）と、既定ドメインが遮断されることがあるか（Dub）で分かれます。
  棒グラフには、4 社で単位が揃う無料プランの独自ドメインの数を載せています
- 検証の手順: Short.io と Dub で 2026-10-15 に行いました。どちらも無料プランのアカウントと API キーをユーザーが作り、AI が (1) 鍵を非対話で使う (2) 短縮リンクを作る (3) API と実際の転送で取得する (4) 同じ URL や同じ末尾で重ねて作る (5) 消して、API と転送の両方で消えたかを見る、の段階を流しました。
  転送先は `example.com` にし、このサイトのドメインは短縮ドメインに繋いでいません。結果は「各対象の詳細」の「検証した内容」に書いています。
  Bitly は無料プランで作ったリンクが広告つきの中間ページを挟み、カスタム末尾や編集済みのリンクを消せないため [13][15]、Rebrandly は消しても月の枠が戻らないため [18]、公開後の確認で同じ手順を取り直せず、公式ページの確認にとどめています
- 鍵を AI エージェントに渡す手段は、[シークレット管理 CLI 6 つの比較](/posts/secret-management-cli/)で比べています。この検証でも、そこで扱った `op run` で鍵を注入しています

## 各対象の詳細

### Short.io

独自ドメインでの短縮リンクを主軸にしたサービスで、無料プランにも複数のドメインと API が含まれます。
無料枠は同時に持てる本数で数えるので、消せば枠が戻ります。

{{< fit run >}}
向く: API で作成から削除までを回し、消したぶんの枠を使い回したい
向かない: 自分のドメインを持たず、電話番号の検証もしたくない（無料ドメインは検証が要る）
{{< /fit >}}

- **料金体系**: Hobby は同時に 2,500 本、独自ドメイン 7、計測 10 万クリック/月で、国別の振り分けとリファラーの非表示が加わります。有料プランには 7 日のトライアルがあり、期間中に解約すればカードに課金されません [1]
- **制約**: 料金ページは無料枠を「一度だけ付与され、アカウントの存続中に使える」と説明しますが、管理画面の「URL が作成されました」の数は、作って消した後に 0 / 1,000 に戻りました。
  つまり枠は現存するリンク数で数えます。無料ドメインは `s.gy` のサブドメインを 3 つまで作れ、名前に使えるのは英数字とハイフンです [2]。
  電話番号を検証するまでサブドメインは有効にならず、リンクは作れても開けません [3]。
  統計 API は実行した当日の curl からのアクセスを数えておらず、bot として除外したのか集計に遅れがあるのかは切り分けられていません [5]
- **前提条件**: 無料ドメインの有効化は、ダッシュボードでサブドメインを選び、組織設定の General で電話番号に SMS を送って行います [3]。
  API キーには権限の絞り込みが無く、アカウント全体の操作ができます
- **検証した内容**: 2026-10-15 に、Free のアカウント（カード未登録）の API キーで実行しました。ドメインは無料の `s.gy` のサブドメインを 1 つ、電話番号の検証を済ませて使っています。

  | 手順 | 呼び出し | 結果 |
  | --- | --- | --- |
  | ドメイン一覧 | `GET /api/domains` | 200。`state: configured` |
  | 作成 | `POST /links`（`domain`・`originalURL`・`path`・`title`） | 200（0.8 秒）。`idString` と https の短縮 URL が返る [4] |
  | 取得 | `GET /links/expand?domain=&path=` / `GET /links/{idString}` | 200 / 200。同じ `idString` |
  | 実転送 | 短縮 URL に HEAD と GET（UA は Chrome と curl の両方） | いずれも 302 → `example.com`、本文 0 バイト。中間ページ無し |
  | 同じ URL を末尾なしで再作成 | `POST /links` | 200、`duplicate: true` で既存の `idString` が返り、本数は増えない |
  | 同じ末尾に別 URL | `POST /links` | 409 `Link already exists` |
  | 統計 | `GET statistics.short.io/statistics/link/{idString}?period=total` | 200 だが `totalClicks` 0（GET 2 回の 30 秒後も 0） |
  | 削除 | `DELETE /links/{idString}` | 200 `success: true`。直後の expand は 404 `Link not found` |
  | 削除直後の転送 | 同じ短縮 URL | 1 秒後はまだ 302。数分後に 404 |
  | 削除後の一覧と管理画面 | `GET /api/links?domain_id=` / Settings の「URL が作成されました」 | count 0 / 0 のうち 1,000（枠が戻る） |

  リンクは一巡で 1 本、ユーザーエージェントの確認で 1 本の計 2 本を作り、どちらも消しています

### Dub

オープンソースで開発されている短縮リンクと計測のサービスで、無料プランに API と独自ドメインが含まれます。
無料枠は月の新規作成数で数え、消しても枠は戻りません。

{{< fit run >}}
向く: 独自ドメインを無料で複数載せ、作る本数は月に少なくてよい
向かない: 作って消すを繰り返す、または既定ドメインのまま curl や監視ツールから転送を確かめたい
{{< /fit >}}

- **料金体系**: Pro は新規 1,000 本/月、計測 5 万イベント/月、独自ドメイン 10、分析の保持 1 年で、`.link` ドメインが 1 つ付き、API は 600 回/分です。有料プランには 14 日のトライアルがあります [6]
- **制約**: 月の枠は請求期間の初めに戻り、未使用分は繰り越しません。消しても月の使用数は減らず、CSV の取り込みで作り過ぎた場合はサポートに枠のリセットを頼めると書かれています [6]。
  計測イベントの枠を超えても既存のリンクは転送され計測も続きますが、分析の閲覧には有料プランが要ります。超過の課金は無く、Free で枠の 4 倍を超えると翌期に数が戻りません [7]。
  統計 API（`/analytics`）は Pro 以上です [10]。実行では 429 `rate_limit_exceeded` が返り、文言からプランの制限とは読み取れませんでした。
  既定ドメイン `dub.sh` は一部のブラウザや ISP に遮断されることがあり、公式は独自ドメインの利用を勧めています [8]
- **前提条件**: 新しいアカウントには `dub.sh` など 6 つの既定ドメインが自動で付きます [9]。商用の利用も無料プランで可で、公正利用の方針を超えると有料プランへの移行を求められることがあります [6]。
  API キーはワークスペース単位で、発行時に読み取り・書き込みの権限を選びます [11]
- **検証した内容**: 2026-10-15 に、Free のワークスペースの API キーで実行しました。独自ドメインは付けず、既定の `dub.sh` を使っています。

  | 手順 | 呼び出し | 結果 |
  | --- | --- | --- |
  | ワークスペース | `GET /workspaces/{slug}` | 200。`plan: free`、`linksUsage` / `linksLimit`、イベントの使用数が返る。一覧の `GET /workspaces` は 401 |
  | 作成 | `POST /links`（`url`・`key`） | 200（0.8 秒）。`shortLink` は `https://dub.sh/<key>` [11] |
  | 取得 | `GET /links/info?linkId=` / `?domain=&key=` | 200 / 200 |
  | 実転送（curl） | 短縮 URL に HEAD と GET（UA は Chrome・curl・独自の 3 通り） | いずれも 403。本文は Vercel の「Security Checkpoint」ページ |
  | 実転送（ブラウザ） | Chromium で短縮 URL を開く | 検査を通って `example.com` に着く |
  | クリックの反映 | `GET /links/info` の `clicks` | 開いて 15 秒後は 0、30 秒後に 1。イベントの使用数も 1 回ごとに増える |
  | 同じ末尾に別 URL | `POST /links` | 409 `conflict` `Duplicate key` |
  | 統計 | `GET /analytics?event=clicks&groupBy=count&linkId=` | 429 `rate_limit_exceeded`（単発でも、時間を置いても同じ） |
  | 削除 | `DELETE /links/{id}` | 200。直後の `GET /links/info` は 404 `not_found` |
  | 削除後の枠 | `GET /workspaces/{slug}` の `linksUsage` | 削除の前後で変わらない（消しても戻らない） |

  スクリプトの不具合によるやり直しとブラウザの確認を含め、月の枠のうち 7 本を使い、すべて消しています。`linksUsage` は 7 のままです

### Bitly

最も広く使われている短縮リンクで、無料プランは広告つきです。
無料枠は月の新規作成数で数え、独自ドメインは無料と最小の有料プランのどちらにもありません。

{{< fit spec >}}
向く: アカウントだけで月に数本を作り、広告つきの中間ページを許容できる
向かない: 独自ドメインを載せたい、または作ったリンクを後から消したり転送先を変えたりしたい
{{< /fit >}}

- **料金体系**: Core は新規 100 本/月、QR コード 5/月、API 5,000 回/月で、リンクと QR コードの転送先の変更が各 5 回/月付きます。クリックの履歴は 30 日です。独自ドメインは Core にも含まれません [12]
- **制約**: 無料アカウントのリンクには、転送先のプレビューと広告を載せた中間ページが挟まり、外すには有料プランへの移行が要ります [13]。
  リンクの枠に達すると、翌月の初めまで新しいリンクの作成も転送先の変更もできません。転送先の変更はリンクの枠から差し引かれます [14]。
  削除はグループか組織の管理者だけができ、カスタム末尾のリンクは削除できず、編集や転送先の変更をしたリンクも削除の選択肢が出ません。
  削除しても末尾は再利用できず、消したリンクのクリック記録も戻りません [15]
- **前提条件**: API の上限は時間あたりで、分あたりはその 10 分の 1、月の回数はプランごとに決まります [16]
- **検証した内容**: 無料プランで作ったリンクが中間ページを挟み、カスタム末尾や編集済みのリンクを消せないため、公開後の確認で同じ手順を取り直せず実行していません。確認したのは公式の料金ページとヘルプ（2026-10-15）です

### Rebrandly

独自ドメインでの短縮リンクを主軸にしたサービスで、無料プランに独自ドメインが 1 つ含まれます。
無料枠は月の新規作成数で数え、消しても枠は戻りません。

{{< fit spec >}}
向く: 独自ドメインを 1 つだけ無料で載せ、月に数本で足りる
向かない: 作って消すを繰り返す、または無料で転送先を変えたい
{{< /fit >}}

- **料金体系**: Essentials は新規 250 本/月、独自ドメイン 2、詳細分析 1 万クリック/月、転送先の変更 10 回/月です。料金ページは年払いの月あたり額を先に表示し、月払いとの差は「最大 31% 節約」と案内しています [17]
- **制約**: 月の枠を持つ項目は作成時に数え、消しても当月の使用数は減りません [18]。無料プランのリンク集と QR コードには透かしが付き、転送先の変更は無料プランにありません [17]
- **前提条件**: 無料プランには独自ドメイン 1 つのほかに、共用の無料ドメイン `rebrand.ly` が付きます [17]
- **検証した内容**: 消しても月の枠が戻らないため、公開後の確認で同じ手順を取り直せず実行していません。確認したのは公式の料金ページとヘルプ（2026-10-15）です

## 用途別の選び方

最初に分かれるのは、無料枠を同時に持てる本数で数えるのか、月の新規作成数で数えるのかです。次に、独自ドメインを無料で載せられるかで分かれます。

- 作って消すを繰り返す。API で作成から削除までを自動化したい → Short.io。決め手は「無料枠」列です。枠は同時に持てる本数で数えるので、消せば戻ります。無料ドメインを使うなら「前提条件」列の電話番号の検証が先に要ります
- 独自ドメインを無料で複数載せたい。月に作る本数は少なくてよい → Dub。決め手は「無料枠」列です。既定ドメインは遮断されることがあり curl からも開けないので、独自ドメインを付ける前提で選びます
- 独自ドメインを 1 つだけ無料で載せ、月に数本で足りる → Rebrandly。決め手は「無料枠」列です。「主な制約」列のとおり、消しても枠は戻りません
- アカウントだけで月に数本。広告つきの中間ページを許容できる → Bitly。決め手は「主な制約」列です。独自ドメインは有料の最小プランにもありません
- 短縮ではなく、サイト全体の訪問数を数えたい → [アクセス解析の無料枠比較](/posts/analytics-free-tier/)が対象です

## よくある質問

### 短縮リンクの無料プランで独自ドメインは使えますか？

Short.io・Dub・Rebrandly の無料プランには独自ドメインが含まれ、数は「無料枠」列のとおりです [1][6][17]。
Bitly は無料プランにも最小の有料プランにも独自ドメインがありません [12]。

### 短縮リンクを消したら無料枠は戻りますか？

Short.io は枠を現存するリンク数で数えるので、消せば戻ります。実行検証でも、作って消した後の管理画面の数が 0 に戻りました [1]。
Dub と Rebrandly は作成時に数えるので、消しても当月の使用数は減りません [6][18]。
Bitly は消せるリンクに条件があり、消しても末尾は再利用できません [15]。

### 短縮リンクを curl や監視ツールから開けますか？

Short.io の短縮 URL は curl からも転送先に 302 で飛びました [4]。
Dub の既定ドメイン `dub.sh` は curl からだと bot の検査で 403 になり、ブラウザからは転送されました。公式も `dub.sh` が遮断されることがあるとして独自ドメインを勧めています [8]。
Bitly の無料プランは転送の前に広告つきの中間ページを挟みます [13]。
