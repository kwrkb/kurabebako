## 結論

国内の事業者が円建て・日本語の画面で一斉配信（メルマガ・お知らせ）を始めるときのメール配信システム 5 つを、
月額の決まり方・初期費用と最低利用期間・無料プランやトライアルの申込条件・API が使えるプランで比べました。
メール配信を無料で、しかも API から試したいなら、コンタクト 500・月 2,500 通の無料プランをカード登録なしで持てる Benchmark Email が条件を満たします。
ただ、Benchmark Email の API はリスト・コンタクト・下書きの管理までで、配信そのものは API キーでは行えず画面操作になります。
画面から送るにも、メールのフッターに載せる名称と住所の設定が先に要ります。
配信通数に関係なく月額を固定したい事業者ならブラストメール、個人や個人事業主が円建ての有料プランを最小の月額で始めるならめる配くんです。
WiLL Mail と配配メールは法人の問い合わせや営業の案内を前提にしていて、個人が自分で申し込んで試す経路がありません。

## 比較の前提

- 対象に含めたもの: 日本語の料金ページと画面を持ち、円建てで一斉配信（メルマガ・お知らせ）を扱う 5 つです。
  Benchmark Email は米国のサービスの日本語版で円建ての料金ページを持ち、ブラストメール・WiLL Mail・める配くん・配配メールは国内の事業者が運営しています
- 除外したもの: Brevo や MailerLite のように海外の無料プランを主役にするサービスは、
  [ニュースレター配信サービス 5 つの無料枠比較](/posts/newsletter-free-tier/)で比べているので、この記事では扱いません。
  登録確認や通知のような 1 通ずつのトランザクション送信も用途が違い、[メール送信 API 5 つの無料枠比較](/posts/email-api-free-tier/)の範囲です
- 検証区分の意味: {{< verified run >}} = AI が実際に動かして確認した / {{< verified spec >}} = 公式ドキュメントで確認したのみ
- 「月額の決まり方」が分かれ目の 1 つです。5 つとも登録アドレス数（コンタクト数）で段が上がる形で、配信通数で月額が変わるものはありません。
  ただ、Benchmark Email の無料プランとめる配くんには月間の配信数の上限があり、める配くんは超えると当月は配信できなくなります。
  ブラストメールと配配メールは配信通数・回数に上限を置いていません
- 「無料で始められるか」は、無料プランを持つ Benchmark Email と、期限付きのトライアルを持つ 3 社、トライアルの記載が無い配配メールに分かれます。
  トライアルの申込条件も違い、ブラストメールは会社名もしくは屋号、WiLL Mail は法人メールアドレスが必須で、める配くんは個人でも申し込めますが申込後に審査があります。
  この記事の線引き（個人アカウントから AI が実際に動かせる）を満たすのは Benchmark Email だけで、実行区分もこの 1 つです
- 「API がある」と「API で配信できる」は一致しません。Benchmark Email は無料プランでも API を使えますが、配信・予約・テスト送信は API キーでは提供されていません。
  ブラストメールは API を標準機能としていますが、プラン別の可否は料金ページから読めません。WiLL Mail は API 連携がプレミアムだけ、める配くんはデータベース API 接続がプロだけです。
  配配メールの料金ページに API の記載はありません
- WiLL Mail のプレミアムの月額は、同じ料金ページの上の比較表が 12,000 円〜、下のプラン詳細が 10,000 円〜で、2026-10-02 と 2026-10-03 の 2 回とも揃っていませんでした。
  この記事は両方をそのまま載せています [9]
- 検証は Benchmark Email の無料プランに 2026-10-03 に行いました。手順は (A) API キーを非対話で使い、アカウント情報・送信元ドメイン・レート制限のヘッダーを記録する
  (B) リストの作成 → コンタクトの追加 → キャンペーンの下書きの作成と更新 → すべての削除、の順に一巡する
  (C) 届く宛先 1 件だけのリストと下書きを API で用意し、配信は画面から行って、結果を API のレポートと受信箱で確かめる、の 3 段階です。
  (C) の送信ボタンだけが画面操作なのは、配信が API キーでは行えないためです。自前ドメインの認証は行っていません（本番のドメインの DNS を触ることになるため）。
  結果は「各対象の詳細」の「検証した内容」に書いています
- API キーを AI エージェントに渡す手段は、[シークレット管理 CLI 6 つの比較](/posts/secret-management-cli/)で比べています。
  この記事の検証でも、そこで扱った `op run` で API キーを注入しています

## 各対象の詳細

### Benchmark Email（日本語版）

米国の配信サービスの日本語版で、円建ての料金ページと日本語の画面を持ちます。
5 つのうち無料プランがあるのはここだけで、API も無料プランから使えます。

- **料金体系**: Free はコンタクト 500・月 2,500 通で、初期費用 0 円です。有料の Pro は登録アドレス 1,000 件の段で 2,500 円/月（月払い）・2,100 円/月（年払い）からで、100,000 件まで段が上がります。
  Pro の追加ユーザーは 1 件 1,900 円/月です。料金ページに税込か税抜かの表記はありません [1]
- **制約**: 送信上限は「登録可能な連絡先数の 5 倍まで、最大月 2,500 通」で、送信元ドメインが未認証の場合は Free が月 1,000 通、有料はプラン数の 2 倍（上限 20,000 通）です [1]。
  Free では全メールと登録フォームに Benchmark Email のロゴが入り、非表示にできるのは有料プランです [1]。
  API のレート制限はアカウント単位で 1 時間 3,600 リクエスト、月はコンタクト上限の 10 倍（Free）か 100 倍（有料）で、超えると 429 と `Retry-After` が返ります [3]。
  キャンペーンの予約・配信・取り消し・テスト送信は API キーでは提供されておらず、Web の画面から行います [4]。
  送信するメールには、配信元の名称・住所・配信停止リンク・迷惑メール報告リンクのフッターが自動で付き、HTML コードエディターで作ったメールでも外せません [15][16]。
  名称と住所は画面の「メール設定 → フッター」で設定するもので、API には設定する口がありません。
  送信したメールは承認の対象で、内容や業種によっては「審査中」や「送信失敗」になります [17]
- **前提条件**: メールアドレスだけで登録でき、料金ページに「クレジットカード情報不要」とあります [1]。
  API は「すべての Benchmark Email プラン（無料トライアル含む）に、追加料金なしで含まれています」で、キーは設定画面の「API キー」から発行し、表示は 1 度だけです [2]。
  認証は `X-API-Key` ヘッダーで、ベース URL はアカウントごとに設定画面に出る値を使います [3]
- **検証した内容**: 公式の料金ページ・API ページ・開発者ドキュメント（レート制限・キャンペーン管理）・ヘルプ（フッター・承認）を確認したうえで、
  2026-10-03 に Free のアカウントで「比較の前提」の 3 段階を実行しました。
  (A) と (B) のコンタクトは予約ドメイン `example.com` のアドレスで、メールは送っていません。(C) はアカウント所有者のアドレス 1 件だけに送っています。

  | 操作 | 結果 |
  | --- | --- |
  | `GET /api/account` ほか読み取り 4 本 | すべて 200。応答は 0.5〜0.7 秒 |
  | `GET /api/email/domain/grey-label` | Free でも `<番号>.jp.benchmarksend.com` の送信元ドメインが 1 件あり、作成時から DKIM 認証済み。自前ドメインの認証をしなくても送信元はある |
  | `POST /api/contact-structure/{id}/lists` | 201、`type: static` |
  | `POST /api/contact`（リストを指定） | 200、`status.primary: Active`。応答 1.2 秒 |
  | `POST /api/email/campaign`（`name` だけ）→ `PATCH` で件名・本文・リストを追加 → 再取得 | 200 → 200 → 200。`draft` のまま反映。`from` が空でも作れ、送信元ドメインのアドレスを渡せば差出人に入る |
  | キャンペーン・コンタクト・リストの `DELETE` | 204 / 200 / 204。再取得はすべて 404 |
  | レート制限のヘッダー | `X-RateLimit-Limit: 3600`、`X-Monthly-Limit: 5000`（= コンタクト上限 500 × 10）。25 リクエストで月の残量は 4,999 → 4,984 |
  | 画面で「今すぐ送信」（宛先 1 件） | フッターの名称・住所が未設定のうちは送れず、「フッター情報が不足しています」と出る。設定後に送信すると**審査中**になり、API の `status` は `manual_review`。約 2 分で `sent` に変わり、完了を知らせるメールは来なかった |
  | `GET /api/reports/email/{id}` | 審査中は 400。送信後は開封 1 件を返す一方、`sent` と `delivered` の集計は 0 のままだった（開封の反映より遅い） |
  | 受信箱（Gmail） | 届いたが**迷惑メールフォルダ**に入った。本文の下に名称・住所と「配信停止 \| 不正行為を報告する」のフッター、その下に「Powered by Benchmark」のロゴが付いていた |
  | 送信済みキャンペーンの削除 | API の `DELETE` は 400 で、画面にも削除の操作がない。送信済みは消せず、履歴として残る |

  迷惑メールの判定は 1 回の観察です。送信元が Free に付く共有サブドメインのままで、自前ドメインは未認証、アカウントは作成当日という条件で、
  Gmail の表示は「以前迷惑メールと判断されたメールに類似」でした。Benchmark Email 側のレポートはバウンスなし・開封ありで、迷惑メール行きは API からは分かりません。

  公式内で数字が揃っていない点が 1 つあります。OpenAPI 定義の説明文は「60 requests per minute」ですが、Rate Limits のページとレスポンスのヘッダーは 1 時間 3,600 です。
  この記事はヘッダーで確かめた 1 時間 3,600 を書いています [3]

### ブラストメール

登録アドレス数で月額が決まり、配信通数では変わらない国内の配信サービスです。
トライアルは 7 日でカード不要ですが、申込は会社名もしくは屋号が必須で、個人の契約は受け付けていません。

- **料金体系**: Light は 4,000 円/月（5,000 件まで）、Standard は 8,000 円/月（1 万件）から 30,000 円/月（5 万件）まで段階制、Pro は 30,000 円/月からです。
  初期費用は 10,000 円で 1 年契約なら半額、Pro は 50,000 円です。契約期間は 3・6・9 か月・1 年から選びます。価格はすべて税抜です [5]。
  配信通数による料金の変動はありません [5]
- **制約**: API は「別途ご申請などは必要なく標準機能」で追加費用もかかりませんが [6]、料金ページの機能表からプラン別の可否は読めず、トライアルで使えるかの記載もありません [5][7]。
  連携方式は XML-RPC と HTTP(S) の 2 種類で、宛先の登録・編集・削除、配信予約、配信結果の取得ができます [7]
- **前提条件**: FAQ に「個人のご契約は承っておりません。ただし個人事業主様の場合はご契約可能です」とあります [6]。
  トライアルの申込フォームは会社名もしくは屋号・お名前・日中つながる電話番号・会社メールアドレス・配信先となるアドレス数が必須です [8]。
  トライアルは開始日を含めて 7 日で、カードは不要、期間後に有料へ自動更新されません [6]
- **検証した内容**: 公式の料金ページ・FAQ・API ページ・申込フォームを確認しました。申込に会社名もしくは屋号が要るため、実行は行っていません。
  屋号で申し込む場合は、トライアル中に API キーが発行されるかを最初に確かめることになります

### WiLL Mail

法人向けの配信サービスで、トライアルは営業がアカウントを案内してから始まります。
API 連携はプレミアムだけで、シンプルでは使えません。

- **料金体系**: シンプルは 4,000 円/月〜（税別）、プレミアムは同じ料金ページ内に 12,000 円/月〜と 10,000 円/月〜の 2 つの表記があります。
  件数ごとの金額は公開されていません。初期費用は不要で、最低利用期間は 1 か月からです [9]
- **制約**: 機能表で API 連携はプレミアムが ◎、シンプルが × です [9]。
  トライアルは「一度の配信につき送信可能なメールアドレスは 5 つまで」で、「社内の方・ご関係者の方向けへのメール配信用」に限り、顧客への配信は不可です [10]
- **前提条件**: トライアルの申込フォームは貴社名・法人メールアドレス・電話番号・導入予定時期・月間配信通数などが項目で、「Gmail などフリーアドレスでのお申し込みは承ることが出来ません」とあります [11]。
  期間は「営業がアカウントをご案内してから 2 週間が基本」です [10]
- **検証した内容**: 公式の料金ページ・FAQ・トップページの申込フォームを確認しました。法人メールアドレスと営業の案内が前提のため、実行は行っていません

### める配くん

5 つのうち有料プランの月額が最も低く、個人でも申し込める国内の配信サービスです。
ただし申込後に審査があり、API 接続はプロだけです。

- **料金体系**: ライトは 2,380 円/月、スタンダードは 7,000 件・月 42,000 通で 3,500 円/月から、100,000 件・月 600,000 通で 50,000 円/月まで段階制です。
  プロは 4,800 円/月から、添付ファイル向けのアタッチは 3,800 円/月です。初期設定費用は 3 か月・6 か月契約で 10,000 円、1 年契約で 0 円です。最低契約期間は 3 か月で、価格はすべて税抜です [12]
- **制約**: 月間配信数を超えると当月の配信ができなくなり、続けるにはプランアップが要ります [12]。機能比較表で「データベース API 接続」が ○ なのはプロだけです [12]
- **前提条件**: トライアルの申込フォームは会社名・お名前・E-mail・電話番号・ホームページアドレス・利用目的と配信内容・配信予定リストの収集方法が項目で、
  個人は会社名の欄に「個人」と書き、ホームページアドレスには本人確認ができる URL（SNS アカウント・個人ブログなど）を入れます。
  申込後に審査があり、利用開始は最短当日〜3 営業日です。フリーメールは審査に時間がかかるか、電話での本人確認になる場合があります。プロのトライアルは申込時のチェックで選べます [13]。
  トライアルは 2 週間・登録アドレス 120 件で、添付ファイル機能を除く全機能が使え、期間後に自動で有料プランへ変更されず、広告も入りません [13]
- **検証した内容**: 公式の料金ページ・申込フォーム・トップページを確認しました。申込後の審査が利用者の操作（フォームの送信と本人確認）になるため、実行は行っていません。
  審査を通せばプロのトライアルで API 接続を試せるので、実行に上げる余地はあります

### 配配メール

国内の配信サービスで、料金は問い合わせになります。公式の料金ページに金額が載っていないため、比較表には「金額は非公開」と書いています。

- **料金体系**: 「初期費用と、プランやアドレス数に応じた月額利用料で構成された料金体系」で、金額の記載はありません [14]
- **制約**: 最低利用期間は課金開始から 12 か月で、以後は 1 か月ごとの自動更新です。配信回数に制限はなく、何回配信しても追加料金は発生しません [14]
- **前提条件**: 問い合わせから始めます。トライアル・API・申込条件の記載は料金ページにありません [14]
- **検証した内容**: 公式の料金ページを確認しました。金額とトライアルが公開されていないため、実行は行っていません

## 用途別の選び方

上から順に答えていくと、条件に合う対象にたどり着きます。各分岐の根拠は下の箇条書きと比較表の列に書いています。

{{< svg src="bulk-email-japan-flow.svg" alt="用途別の判断フロー。まず無料で API からリストとコンタクトを作って試したいなら Benchmark Email、配信通数に関係なく月額を固定したい事業者で会社名か屋号があるならブラストメール、個人や個人事業主が円建ての有料プランを最小の月額で始めるならめる配くん、法人で外部システムとの API 連携が要り営業の案内つきのトライアルを受け入れられるなら WiLL Mail、どれにも当たらず料金を問い合わせて決めるなら配配メール" caption="図: 用途別の判断フロー" >}}

- まず無料で、API からリストとコンタクトを作って試したい → Benchmark Email。「無料枠」列のとおりコンタクト 500・月 2,500 通をカード登録なしで持て、
  「前提条件」列のとおり API は無料プランから使えます。ただし「主な制約」列のとおり、配信そのものは画面操作で、フッターの名称と住所の設定が先に要ります
- 配信通数に関係なく月額を固定したい事業者で、会社名か屋号がある → ブラストメール。「料金」列のとおり登録アドレス数だけで段が決まり、
  「無料枠」列の 7 日のトライアルはカード不要です。「前提条件」列のとおり個人の契約は受け付けていません
- 個人や個人事業主が、円建ての有料プランを最小の月額で始めたい → める配くん。「料金」列の 2,380 円/月は 5 つで最も低く、「前提条件」列のとおり個人でも申し込めます。
  ただし「主な制約」列のとおり API 接続はプロだけで、申込後の審査が挟まります
- 法人で、外部システムとの API 連携が要る。営業の案内つきのトライアルを受け入れられる → WiLL Mail のプレミアム。「主な制約」列のとおり API 連携はプレミアムだけで、
  「前提条件」列のとおり法人メールアドレスでの申込が前提で、フリーアドレスは受け付けていません
- どれにも当たらず、料金を問い合わせて決める → 配配メール。「料金」列のとおり金額は非公開で、「主な制約」列のとおり最低利用期間が 12 か月です

海外の無料プランを主役にした一斉配信は[ニュースレター配信サービス 5 つの無料枠比較](/posts/newsletter-free-tier/)、
1 通ずつのトランザクション送信は[メール送信 API 5 つの無料枠比較](/posts/email-api-free-tier/)の範囲です。
