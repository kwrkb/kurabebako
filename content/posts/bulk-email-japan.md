## 結論

国内の事業者が円建て・日本語の画面で一斉配信（メルマガ・お知らせ）を始めるときのメール配信システム 5 つを、最小の有料プランを主役に、
月額の決まり方・初期費用と最低利用期間・無料プランやトライアルの申込条件・API が使えるプランで比べました。

- **無料で、API から試したい** → Benchmark Email。カード登録なしの無料プランを持つのはここだけです。
  ただし API はリスト・コンタクト・下書きの管理までで、配信そのものは画面操作になります
- **配信通数に関係なく月額を固定したい事業者** → ブラストメール。個人が円建ての有料プランを最小の月額で始めるなら、める配くんです
- **法人で、営業の案内や問い合わせから始める** → WiLL Mail か配配メール。個人が自分で申し込んで試す経路はありません

| こういう条件なら | 対象 | 決め手 |
| --- | --- | --- |
| 無料で、API からリストとコンタクトを作って試したい | Benchmark Email | 「無料枠」列（カード不要の無料プラン）と「前提条件」列（API は無料プランから） |
| 配信通数に関係なく月額を固定したい事業者（会社名か屋号がある） | ブラストメール | 「料金」列（登録アドレス数だけで段が決まる）と「無料枠」列（カード不要のトライアル） |
| 個人や個人事業主が、円建ての有料プランを最小の月額で始めたい | める配くん | 「料金」列（5 つで最も低い月額）と「前提条件」列（個人も申込可） |
| 法人で、外部システムとの API 連携が要る | WiLL Mail のプレミアム | 「主な制約」列（API 連携はプレミアムだけ）と「前提条件」列（法人メールアドレスが必須） |
| 料金を問い合わせて決める | 配配メール | 「料金」列（金額は非公開）と「主な制約」列（最低利用期間が長い） |

海外のサービスを無料プランを主役に比べた記事は[海外のニュースレター配信サービス 5 つの無料枠比較](/posts/newsletter-free-tier/)です。
無料のまま API で配信まで閉じたい場合はそちらを見てください。

## 比較の前提

- 対象に含めたもの: 日本語の料金ページと画面を持ち、円建てで一斉配信（メルマガ・お知らせ）を扱う 5 つです。
  Benchmark Email は米国のサービスの日本語版で円建ての料金ページを持ち、ブラストメール・WiLL Mail・める配くん・配配メールは国内の事業者が運営しています
- 除外したもの: Brevo や MailerLite のように海外の無料プランを主役にするサービスは、
  [海外のニュースレター配信サービス 5 つの無料枠比較](/posts/newsletter-free-tier/)で比べているので、この記事では扱いません。
  登録確認や通知のような 1 通ずつのトランザクション送信も用途が違い、[メール送信 API 5 つの無料枠比較](/posts/email-api-free-tier/)の範囲です
- 検証区分の意味: {{< verified run >}} = AI が実際に動かして確認した / {{< verified spec >}} = 公式ドキュメントで確認したのみ
- 料金表記の注意: 金額は各社の料金ページの表記のままです。ブラストメール・WiLL Mail・める配くんは税抜（税別）の表記で、
  Benchmark Email の料金ページには税込か税抜かの表記がありません。
  WiLL Mail のプレミアムの月額は、同じ料金ページの上の比較表と下のプラン詳細で金額が揃っておらず（2026-10-02 と 2026-10-03 の 2 回とも）、
  この記事は両方をそのまま載せています [9]
- 選び方の軸: 「料金」列は、5 つとも登録アドレス数で段が上がり、配信通数では変わりません。分かれるのは初期費用と最低利用期間の有無です。
  「無料枠」列は、無料プランか・期限付きのトライアルか・記載なしかに加えて、申込条件（個人の可否・会社名や法人メールアドレスの要否・審査の有無）で分かれます。
  個人アカウントから AI が実際に動かせる（この記事の線引き）のは Benchmark Email だけで、実行区分もこの 1 つです。
  「主な制約」列は、「API がある」と「API で配信できる」が一致しない点が分かれ目です
- 検証の手順: Benchmark Email の無料プランに 2026-10-03 に行いました。(A) API キーを非対話で使って読み取り、(B) リスト → コンタクト → 下書きの作成と削除を一巡し、
  (C) 宛先 1 件のリストと下書きを API で用意して配信だけ画面から行い、API のレポートと受信箱で確かめる、の 3 段階です。
  自前ドメインの認証は行っていません（本番のドメインの DNS を触ることになるため）。結果は「各対象の詳細」の「検証した内容」に書いています
- API キーを AI エージェントに渡す手段は、[シークレット管理 CLI 6 つの比較](/posts/secret-management-cli/)で比べています。
  この記事の検証でも、そこで扱った `op run` で API キーを注入しています

## 各対象の詳細

### Benchmark Email（日本語版）

米国の配信サービスの日本語版で、円建ての料金ページと日本語の画面を持ちます。
5 つのうち無料プランがあるのはここだけで、API も無料プランから使えます。

{{< fit run >}}
向く: 無料で、API からリストとコンタクトを作って試したい。カード登録なしで始めたい
向かない: 配信まで API で閉じたい（配信は画面操作）。無料のままメールにサービスのロゴを出したくない
{{< /fit >}}

- **料金体系**: Pro の追加ユーザーは 1 件 1,900 円/月です [1]
- **制約**: 送信上限は「登録可能な連絡先数の 5 倍まで」で、送信元ドメインが未認証の場合は有料でもプラン数の 2 倍（上限 20,000 通）に下がります [1]。
  API のレート制限を超えると 429 と `Retry-After` が返ります [3]。
  送信するメールには、配信元の名称・住所・配信停止リンク・迷惑メール報告リンクのフッターが自動で付き、HTML コードエディターで作ったメールでも外せません [15][16]。
  名称と住所は画面の「メール設定 → フッター」で設定するもので、API には設定する口がありません。
  送信したメールは承認の対象で、内容や業種によっては「審査中」や「送信失敗」になります [17]
- **前提条件**: API キーは設定画面の「API キー」から発行し、表示は 1 度だけです [2]。
  ベース URL はアカウントごとに設定画面に出る値を使います [3]
- **検証した内容**: 公式の料金ページ・API ページ・開発者ドキュメント（レート制限・キャンペーン管理）・ヘルプ（フッター・承認）を確認したうえで、
  2026-10-03 に Free のアカウントで「比較の前提」の 3 段階を実行しました。
  (A) と (B) のコンタクトは予約ドメイン `example.com` のアドレスで、メールは送っていません。(C) はアカウント所有者のアドレス 1 件だけに送っています。

  | 操作 | 結果 |
  | --- | --- |
  | `GET /api/account` ほか読み取り 4 本 | すべて 200。応答は 0.5〜0.7 秒 |
  | `GET /api/email/domain/grey-label` | Free でも `<番号>.jp.benchmarksend.com` の送信元ドメインが 1 件あり、作成時から DKIM 認証済み。自前ドメインの認証をしなくても送信元はある |
  | `POST /api/contact-structure/{id}/lists` | 201、`type: static` |
  | `POST /api/contact`（リストを指定） | 200、`status.primary: Active`。応答 1.2 秒 |
  | `POST /api/email/campaign`（`name` だけ）→ `PATCH` で件名・本文・リストを追加 → 再取得 | 200 → 200 → 200。`draft` のまま反映。`from` が空でも作れ、送信元ドメインのアドレスを渡せば差出人に入る |
  | キャンペーン・コンタクト・リストの `DELETE` | 204 / 200 / 204。再取得はすべて 404 |
  | レート制限のヘッダー | `X-RateLimit-Limit: 3600`、`X-Monthly-Limit: 5000`（= コンタクト上限 500 × 10）。25 リクエストで月の残量は 4,999 → 4,984 |
  | 画面で「今すぐ送信」（宛先 1 件） | フッターの名称・住所が未設定のうちは送れず、「フッター情報が不足しています」と出る。設定後に送信すると**審査中**になり、API の `status` は `manual_review`。約 2 分で `sent` に変わり、完了を知らせるメールは来なかった |
  | `GET /api/reports/email/{id}` | 審査中は 400。送信後は開封 1 件を返す一方、`sent` と `delivered` の集計は 0 のままだった（開封の反映より遅い） |
  | 受信箱（Gmail） | 届いたが**迷惑メールフォルダ**に入った。本文の下に名称・住所と「配信停止 \| 不正行為を報告する」のフッター、その下に「Powered by Benchmark」のロゴが付いていた |
  | 送信済みキャンペーンの削除 | API の `DELETE` は 400 で、画面にも削除の操作がない。送信済みは消せず、履歴として残る |

  迷惑メールの判定は 1 回の観察です。送信元が Free に付く共有サブドメインのままで、自前ドメインは未認証、アカウントは作成当日という条件で、
  Gmail の表示は「以前迷惑メールと判断されたメールに類似」でした。Benchmark Email 側のレポートはバウンスなし・開封ありで、迷惑メール行きは API からは分かりません。

  公式内で数字が揃っていない点が 1 つあります。OpenAPI 定義の説明文は「60 requests per minute」ですが、Rate Limits のページとレスポンスのヘッダーは 1 時間 3,600 です。
  この記事はヘッダーで確かめた 1 時間 3,600 を書いています [3]

### ブラストメール

登録アドレス数で月額が決まり、配信通数では変わらない国内の配信サービスです。
トライアルはカード不要ですが、申込は会社名もしくは屋号が必須で、個人の契約は受け付けていません。

{{< fit spec >}}
向く: 配信通数に関係なく月額を固定したい事業者で、会社名か屋号がある
向かない: 個人として契約したい。トライアル中に API を試せるかを申込前に確かめたい
{{< /fit >}}

- **料金体系**: 表に載せた段階のほかに追加の段はなく、配信通数による料金の変動もありません [5]
- **制約**: API の連携方式は XML-RPC と HTTP(S) の 2 種類で、宛先の登録・編集・削除、配信予約、配信結果の取得ができます [7]。
  「別途ご申請などは必要なく標準機能」で追加費用もかかりませんが [6]、料金ページの機能表からプラン別の可否は読めず、トライアルで使えるかの記載もありません [5][7]
- **前提条件**: FAQ に「個人のご契約は承っておりません。ただし個人事業主様の場合はご契約可能です」とあります [6]。
  トライアルの申込フォームは会社名もしくは屋号・お名前・日中つながる電話番号・会社メールアドレス・配信先となるアドレス数が必須です [8]
- **検証した内容**: 公式の料金ページ・FAQ・API ページ・申込フォームを確認しました。申込に会社名もしくは屋号が要るため、実行は行っていません。
  屋号で申し込む場合は、トライアル中に API キーが発行されるかを最初に確かめることになります

### WiLL Mail

法人向けの配信サービスで、トライアルは営業がアカウントを案内してから始まります。
API 連携はプレミアムだけで、シンプルでは使えません。

{{< fit spec >}}
向く: 法人で、外部システムとの API 連携が要り、営業の案内つきのトライアルを受け入れられる
向かない: 個人やフリーアドレスで申し込みたい。トライアルで顧客に配信して確かめたい
{{< /fit >}}

- **料金体系**: 件数ごとの金額は公開されていません [9]
- **制約**: トライアルは「社内の方・ご関係者の方向けへのメール配信用」に限り、顧客への配信は不可です [10]
- **前提条件**: トライアルの申込フォームは貴社名・法人メールアドレス・電話番号・導入予定時期・月間配信通数などが項目で、「Gmail などフリーアドレスでのお申し込みは承ることが出来ません」とあります [11]
- **検証した内容**: 公式の料金ページ・FAQ・トップページの申込フォームを確認しました。法人メールアドレスと営業の案内が前提のため、実行は行っていません

### める配くん

5 つのうち有料プランの月額が最も低く、個人でも申し込める国内の配信サービスです。
ただし申込後に審査があり、API 接続はプロだけです。

{{< fit spec >}}
向く: 個人や個人事業主が、円建ての有料プランを最小の月額で始めたい
向かない: 申込後の審査や電話での本人確認を待たずに始めたい。ライトやスタンダードで API 接続を使いたい
{{< /fit >}}

- **料金体系**: 初期設定費用は 3 か月・6 か月契約で 10,000 円、1 年契約で 0 円です [12]
- **制約**: 月間配信数を超えたあと配信を続けるには、プランアップが要ります [12]
- **前提条件**: トライアルの申込フォームは会社名・お名前・E-mail・電話番号・ホームページアドレス・利用目的と配信内容・配信予定リストの収集方法が項目で、
  個人は会社名の欄に「個人」と書き、ホームページアドレスには本人確認ができる URL（SNS アカウント・個人ブログなど）を入れます。
  プロのトライアルは申込時のチェックで選べます。トライアルは添付ファイル機能を除く全機能が使え、広告も入りません [13]
- **検証した内容**: 公式の料金ページ・申込フォーム・トップページを確認しました。申込後の審査が利用者の操作（フォームの送信と本人確認）になるため、実行は行っていません。
  審査を通せばプロのトライアルで API 接続を試せるので、実行に上げる余地はあります

### 配配メール

国内の配信サービスで、料金は問い合わせになります。公式の料金ページに金額が載っていないため、比較表には「金額は非公開」と書いています。

{{< fit spec >}}

向かない: 申込前に金額を知りたい。短い期間だけ使いたい

- **料金体系**: 「初期費用と、プランやアドレス数に応じた月額利用料で構成された料金体系」で、金額の記載はありません [14]
- **制約**: 何回配信しても追加料金は発生しません [14]
- **前提条件**: トライアル・API・申込条件の記載は料金ページにありません [14]
- **検証した内容**: 公式の料金ページを確認しました。金額とトライアルが公開されていないため、実行は行っていません

  ただし配信そのものは画面操作で、フッターの名称と住所の設定が先に要ります

## よくある質問

### 無料のメール配信システムで、API から配信までできますか？

この 5 つの中では、できません。無料プランを持つのは Benchmark Email だけで、その API はリスト・コンタクト・キャンペーンの下書きの管理までです。
配信・予約・テスト送信は API キーでは提供されておらず、Web の画面から行います [4]。
API で配信まで閉じたい場合は、海外のサービスを比べた[海外のニュースレター配信サービス 5 つの無料枠比較](/posts/newsletter-free-tier/)の範囲です。

### 個人でも申し込めますか？

Benchmark Email はメールアドレスだけで登録できます [1]。める配くんは個人でも申し込めますが、申込後に審査があります [13]。
ブラストメールは個人の契約を受け付けておらず（個人事業主は可）[6]、WiLL Mail は法人メールアドレスが必須です [11]。配配メールは問い合わせから始めます [14]。

### 月額は配信した通数で変わりますか？

5 つとも、月額は登録アドレス数（コンタクト数）で決まり、配信通数では変わりません [1][5][9][12][14]。
ただし無料プランやトライアル、める配くんの各プランには月間の配信数の上限があり、める配くんは超えると当月は配信できません [12]。

### トライアルにクレジットカードは要りますか？

Benchmark Email の無料プランとブラストメールのトライアルは、カードなしで始められます [1][6]。
WiLL Mail とめる配くんのトライアルは申込フォームの送信と案内・審査を経て始まり、料金ページにカードの要否の記載はありません [11][13]。
