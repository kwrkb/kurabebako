## 結論

AI にレンタルサーバーの設定やサイトの公開を任せたい人向けに、国内の共用レンタルサーバー 5 社の標準クラスのプランを比べました。
軸は「最初に自分ですること」「AI に任せられた範囲」「自分の操作が残るところ」です。

- **サーバー設定のほぼ全部を AI に任せたい** → エックスサーバー。自分ですることはアカウント作成と API キーの発行までで、無料お試し中でも設定の作成から削除まで AI で通りました。残るのは、お試し中のメールと FTP アカウントの操作です
- **ドメイン・SSL・WordPress・メールまで任せ、月額を抑えたい** → ロリポップ!。自分ですることはトークンの発行までで、追加費用なしで AI から操作できます。データベース・cron・FTP の設定は自分の操作が残ります
- **AI にはファイルの操作だけ頼み、カード登録なしで試したい** → さくらのレンタルサーバ。自分ですることは会員登録だけですが、サーバー設定の変更はすべて自分でコントロールパネルを操作することになります

| こういう条件なら | 対象 | 決め手 |
| --- | --- | --- |
| サーバー設定のほぼ全部を AI に任せたい | エックスサーバー | 準備は API キーの発行まで（「前提条件」列）。残る操作はお試し中のメールと FTP アカウント（「主な制約」列） |
| ドメイン・SSL・WordPress・メールまで任せ、月額を抑えたい | ロリポップ! | 準備はトークンの発行まで（「前提条件」列）。残る操作はデータベース・cron・FTP（「主な制約」列）と、通常料金（「料金」列） |
| AI にはファイルの操作だけ頼み、カード登録なしで試したい | さくらのレンタルサーバ | 準備は会員登録だけ（「無料枠」列）。設定の変更はすべて自分の操作（「主な制約」列） |

## 比較の前提

- 対象に含めたもの: 国内事業者の共用レンタルサーバーのうち、公式サイトで料金と仕様を公開し、個人が申し込める 5 サービスです。
  各社の「標準」に当たるプラン（WordPress と SSH が使える最下位か、その一つ上）で揃えました。
  ロリポップ!とさくらはさらに安いプランがありますが、SSH や公開 API の対象外なので載せていません
- 除外したもの: VPS と静的サイトのホスティング。root 権限や無料枠の有無で比較軸が変わるため、
  [国内 VPS の最小プラン比較](/posts/vps-japan-minimum-plan/)と[静的サイトの無料ホスティング比較](/posts/static-site-hosting-free-tier/)で扱っています。
  法人向けの XServer ビジネスや、さくらのマネージドサーバも対象外です
- 検証区分の意味: {{< verified run >}} = AI が実際に動かして確認した / {{< verified spec >}} = 公式ドキュメントで確認したのみ
- 料金表記の注意: 料金は各社の公式ページの税込表記を載せています。エックスサーバーと ConoHa WING のキャンペーン価格は、どちらも申込み時の割引で初回の契約期間にだけ効きます。
  棒グラフはキャンペーンを含めず、ConoHa WING は時間課金の月上限、mixhost は更新料金を使います。契約期間や初回・更新の違いは比較表で確認してください
- 「公式の自動化手段」は、事業者自身が公開している API・CLI・MCP サーバー・AI エージェント向けスキルを指します。
  cPanel の API のように、事業者がサポート対象外としているものは含めていません
- 選び方の軸: 「前提条件」列が「最初に自分ですること」、「主な制約」列が「AI に任せられる範囲と、自分の操作が残るところ」に当たります。
  「主な制約」列は、公式の自動化手段がどこまで届くかで分かれます。エックスサーバーはサーバー設定のほぼ全項目、ロリポップ!はドメインから WordPress・メールまで、ConoHa WING はファイルのアップロードだけで、さくらと mixhost には公開の手段がありません。
  「無料枠」列は、無料お試しの有無と期間、カード登録の要否、お試し中に止まる機能で分かれます。
  「料金」列は、通常料金の安さに加えて、キャンペーン・初回価格・時間課金のどれで表示しているかを見分ける必要があります
- 検証の手順: エックスサーバーに 2026-09-05、お試し中のサーバーで行いました。API キーを発行し、REST API での読み取りと設定の作成・削除、CLI と MCP サーバーの呼び出しまでを通しています。
  ほかの 4 社は公式ページの確認にとどめ、結果は「各対象の詳細」の「検証した内容」に書いています

## 各対象の詳細

### エックスサーバー スタンダード

自分ですることはアカウントの作成と API キーの発行までで、そこから先のサーバー設定のほぼ全項目を AI に任せられます。
この記事では無料お試し中に API キーを発行し、REST API・CLI・MCP のそれぞれを AI から動かしました。

{{< fit run >}}
向く: API キーを発行したら、DNS・cron・SSH 鍵・データベースの設定まで AI に任せたい
向かない: お試し中に、メールや追加の FTP アカウントの操作まで AI に任せたい
{{< /fit >}}

- **料金体系**: 契約期間分を一括前払いし、支払いはクレジットカード・銀行振込・ペイジー・コンビニ払い・Paidy・プリペイドに対応します [1]。
  最大 30% オフキャンペーンは 2026-10-05 17:00 から 2026-11-04 17:00 までの新規申込みが対象で、初回の利用料金に対する割引です。
  割引率は契約期間で段階が付き、12 か月 10%・24 か月 20%・36 か月 30% です。3 か月と 6 か月はキャンペーンページの対象に載っていません。
  2026-10-05 17:00 まで実施していた半額キャッシュバック（満 6 か月利用後の申請が要る方式）は終了しています [30]
- **制約**: お試し期間中の制限について、FAQ は「など」と書いており、一覧は網羅的ではありません [2][3]。
  API のレート制限を超えると 429 と `Retry-After` が返ります。API からサーバーを新規申込するにはプリペイド残高 20,000 円以上が要ります [5][6]
- **前提条件**: API キーは `xs_` で始まり、対象プランはスタンダード・プレミアム・ビジネスです。CLI（`xserver-cli`）と MCP サーバー（`xserver-mcp`）は npm で配布されています。
  MCP からのサーバー新規申込は環境変数で明示的に許可しないと実行できません [5][7][8][9]
- **検証した内容**: 2026-09-05 に、お試し 2 日目のサーバーに対して実行しました。認証は `Authorization: Bearer <API キー>` です。
  結果は次のとおりです。

  | 操作 | 結果 |
  | --- | --- |
  | `GET /v1/me`、`GET /v1/server` | 200。契約は `plan_id: standard`、`status: active`。お試し中でも API キーの権限は `full` |
  | 読み取り 13 エンドポイント（サーバー情報・使用量・ドメイン・DNS・SSL・SSH・cron・FTP・DB・PHP・WordPress・ログ） | すべて 200 |
  | cron の追加 → 一覧 → 削除 | 200 / 200 / 200。追加 0.77 秒、削除 1.03 秒 |
  | SSH 公開鍵の登録 → 一覧 → 削除 | 200。登録すると「SSH 接続と国外アクセス制限を有効化」、最後の鍵を消すと自動で無効に戻る |
  | 初期ドメインへのサブドメイン追加 | **409**「初期ドメインにはサブドメインを追加することはできません」 |
  | メールアカウントの作成 | **409**「試用期間中のため、メールアカウントの追加はできません」 |
  | FTP アカウントの追加 | **409**「試用期間中のため FTP アカウントを追加できません」 |
  | `npx xserver-cli@1.4.0 --format json server info` | 環境変数 `XSERVER_API_KEY` と `XSERVER_SERVERNAME` だけで認証が通り、API と同じ JSON を返す |
  | `npx xserver-mcp@1.4.0 --services=server` に `tools/list` | ツール 118 個（cron・SSH 鍵・WordPress・メール・DNS・SSL・DB・バックアップなど） |

  お試し中の制限は公式の 3 項目のとおり API 側でも 409 で止まり、それ以外の設定は本契約と同じように通りました。
  検証で作った cron と SSH 鍵はその場で削除し、終了時に cron 0 件・鍵 0 件・SSH 無効を確認しています。
  API の実行ログは `GET /v1/logs` で呼び出しごとに残るため、AI に操作させた後の監査に使えます

### ロリポップ! スタンダード

自分ですることはユーザー専用ページでのトークンの発行までで、ドメイン・SSL・WordPress・メールの設定を追加費用なしで AI に任せられます。
MySQL・cron・FTP は「近日公開」で、当面は自分の操作が残ります。

{{< fit spec >}}
向く: トークンを発行したら、ドメイン・SSL・WordPress・メールの設定を AI に任せ、月額を抑えたい
向かない: MySQL・cron・FTP の設定まで AI に任せたい。お試し中にメールを使いたい
{{< /fit >}}

- **料金体系**: ハイスピード（12 か月 1,045 円）以上は LiteSpeed になり、12 か月以上の契約で独自ドメインが 2 つ無料になります [10]
- **制約**: 公開 API は Personal Access Token（`lp_pat_` で始まる）による Bearer 認証で、`domains:read` や `wordpress:write` のようなスコープを発行時に選びます。
  レート制限はアカウント単位で、日本時間 9:00 にリセットされます。対象外のプランで呼んだときのエラーコードは `plan_not_allowed` です [11][12]。
  お試し期間中（入金前）はメールマガジンとメーリングリストも使えず、入金後に使えるようになります [15]。
  入金前にメール機能がどこまで止まるかは、この記事では実行して確かめていません
- **前提条件**: PAT の平文は発行時にしか表示されません。MCP サーバーは `https://lolipop.jp/api/v1/mcp` への HTTP 接続で、Claude Code なら `claude mcp add` に URL と Authorization ヘッダーを渡すだけです [12][13]。
  お試し期間中に PAT を発行できるかは、この記事では確認していません
- **検証した内容**: {{< verified spec >}}。公式の API ドキュメント（OpenAPI 3.1）で、エンドポイントが `/me`・`/domains`・`/subdomains`・`/php`・`/mail`・`/ssl`・`/wordpress`・`/server` の 8 系統であることを確認しました [12]。別に配布されている「AI エージェント Skills」は、API ではなく SSH（`sshpass`）と Playwright によるブラウザ自動化で
  管理画面を操作する構成です。スタンダード以上が必要です [16][17]

### さくらのレンタルサーバ スタンダード

自分ですることは会員登録とお試しの申込みだけで、クレジットカードの登録も要りません。
ただ、レンタルサーバ向けの公開 API は無く、AI に任せられるのは SSH 経由のファイル操作までで、サーバー設定の変更は自分でコントロールパネルを操作することになります。

{{< fit spec >}}
向く: AI にはファイルの操作だけ頼み、カード登録なしで長めに試したい。通常料金を抑えたい
向かない: サーバー設定の変更まで AI に任せたい。短い期間で解約したい（最低利用期間がある）
{{< /fit >}}

- **料金体系**: ライト（12 か月 165 円）は SSH と cron が使えず、12 か月以上の一括払いのみです [18][19]
- **制約**: さくらインターネットが API を出しているのは VPS・クラウド・ウェブアクセラレータで、レンタルサーバにはありません [21]。
  最低利用期間の間は解約できません [19][20]
- **前提条件**: お試し中に他社管理のドメインを移管せずに使えるのはクレジットカード払いの場合で、請求書払い・銀行振込では入金の確認後に使えます [19][20]
- **検証した内容**: {{< verified spec >}}。料金ページは JavaScript で描画されるため、ブラウザで料金表を取得しました [18]

### ConoHa WING ベーシック

自分ですることは支払い方法の登録と、公開フォルダに限定した FTP アカウントの作成で、AI に任せられるのは公式の「サイト公開スキル」によるファイルの公開までです。
時間課金の「通常料金」があり、最低利用期間なしで使えるのが他社と違う点です。

{{< fit spec >}}
向く: AI にはファイルを上げてもらうだけでよく、時間課金で短期間だけ使いたい
向かない: サーバー設定やファイルの削除まで AI に任せたい。無料お試しで先に試したい
{{< /fit >}}

- **料金体系**: WINGパックは 3〜36 か月の一括前払いで、価格は 2026-10-08 の確認時点のものです [22]。

- ドメイン・SSL・WordPress・メールまで AI に任せ、月額を抑えたい → ロリポップ!。決め手は「主な制約」列と「料金」列です。
  先にすることはトークンの発行で、MySQL・cron・FTP の設定は自分の操作として残ります
- AI にはファイルの操作だけ頼み、カード登録なしで長めに試したい → さくらのレンタルサーバ。決め手は「無料枠」列と「料金」列です。
  先にすることは会員登録だけで、サーバー設定の変更はすべてコントロールパネルでの自分の操作になります。最低利用期間があり、お試し中に他社管理のドメインを使うなら、クレジットカード払いで申し込む必要があります

- cPanel は自分で操作でき、お試しの代わりに返金保証で足りる → mixhost。決め手は「無料枠」列と「料金」列です。
  AI に任せられる公式の手段は無く、返金には解約手続きとサポートへの連絡が要り、初回価格は更新時に上がります

## よくある質問

### AI にレンタルサーバーの設定を任せるには、最初に何を用意しますか？

エックスサーバーは XServer アカウントと、「API キー管理」で発行する API キーです。お試し中でも発行でき、CLI と MCP を使うなら Node.js も要ります [2][5][7][9]。
ロリポップ!はユーザー専用ページで発行する Personal Access Token で、スタンダード以上のプランが対象です。MySQL・cron・FTP の設定は近日公開まで自分の操作が残ります [11][12]。
さくらのレンタルサーバと mixhost に公開 API は無く、設定はコントロールパネルや cPanel での自分の操作です。ConoHa WING は公開フォルダ限定の FTP アカウントを用意すると、公式スキルでファイルの公開を任せられます [21][24][29]。

### 無料で試せるのはどれですか？

エックスサーバーとロリポップ!は 10 日間、さくらのレンタルサーバは 14 日間の無料お試しがあり、さくらはクレジットカード登録が要りません [2][15][19][20]。
ConoHa WING と mixhost に無料お試しは無く、ConoHa WING は WINGパックの申込み月の料金が無料、mixhost は初回申込みから 30 日以内の返金保証です [22][26]。

### お試し期間中に使えない機能はありますか？

エックスサーバーはメールアカウントの作成・プログラムからのメール送受信・追加 FTP アカウントが不可で、検証では API でも 409 が返りました [2][3]。
ロリポップ!は入金前はメールが使えません [15]。さくらのレンタルサーバは、他社管理のドメインを移管せずに使うこと（カード払いなら可）と、バックアップ&ステージング・コンテンツブーストが使えません [19][20]。

### 表示されている月額は、更新後も同じですか？

mixhost の表示価格は初回のみで、通常料金で自動更新されます [25]。ConoHa WING の WINGパックの価格は申込み時のみの割引で、更新料金とは異なります [31]。
エックスサーバーのキャンペーン価格も初回の契約期間にだけ効く申込み時の割引で、更新時は通常料金です [30]。
