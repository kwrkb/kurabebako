## 結論

国内の共用レンタルサーバー 5 社の標準クラスのプランを、「AI エージェントや CLI から、公式の手段でどこまで操作できるか」を軸に比べました。
DNS・cron・SSH 鍵・データベースまで API で設定したいなら、エックスサーバーで決まります。
公式の REST API・CLI・MCP サーバーが揃い、10 日間の無料お試し中でも API キーを発行して作成から削除まで通りました。
ただ、操作したいのがドメイン・SSL・WordPress・メールまでで、12 か月契約の通常料金を抑えたいならロリポップ!が候補です。
API が要らず、カード登録なしで 2 週間試したいなら、さくらのレンタルサーバが候補です。12 か月契約の通常料金は 5 社で最も安く済みます。

## 比較の前提

- 対象に含めたもの: 国内事業者の共用レンタルサーバーのうち、公式サイトで料金と仕様を公開し、個人が申し込める 5 サービスです。
  各社の「標準」に当たるプラン（WordPress と SSH が使える最下位か、その一つ上）で揃えました。
  ロリポップ!とさくらはさらに安いプランがありますが、SSH や公開 API の対象外なので載せていません
- 除外したもの: VPS と静的サイトのホスティング。root 権限や無料枠の有無で比較軸が変わるため、
  [国内 VPS の最小プラン比較](/posts/vps-japan-minimum-plan/)と[静的サイトの無料ホスティング比較](/posts/static-site-hosting-free-tier/)で扱っています。
  法人向けの XServer ビジネスや、さくらのマネージドサーバも対象外です
- 検証区分の意味: {{< verified run >}} = AI が実際に動かして確認した / {{< verified spec >}} = 公式ドキュメントで確認したのみ
- 料金は各社の公式ページの税込表記を載せています。エックスサーバーは通常料金を支払った後に申請するキャッシュバック、ConoHa WING は申込み時のみの割引です。
  棒グラフはキャンペーンを含めず、ConoHa WING は時間課金の月上限、mixhost は更新料金を使います。契約期間や初回・更新の違いは比較表で確認してください
- 「公式の自動化手段」は、事業者自身が公開している API・CLI・MCP サーバー・AI エージェント向けスキルを指します。
  cPanel の API のように、事業者がサポート対象外としているものは含めていません

## 各対象の詳細

### エックスサーバー スタンダード

REST API・CLI・MCP サーバーの 3 つが公式に揃い、サーバー設定のほぼ全項目を対象にしています。
この記事では 10 日間の無料お試し中に API キーを発行し、REST API・CLI・MCP のそれぞれを動かしました。

- **料金体系**: スタンダードは 12 か月契約で月 1,100 円、36 か月で 990 円、3 か月で 1,320 円です。
  初期費用は無料で、契約期間分を一括前払いします。
  支払いはクレジットカード・銀行振込・ペイジー・コンビニ払い・Paidy・プリペイドに対応します [1]。
  2026-09-07 17:00〜2026-10-05 17:00 の新規申込みは、12 か月以上の契約で初回利用料金の半額キャッシュバックが対象です。
  12 か月契約では 13,200 円を支払い、6,600 円を受け取ると実質月 550 円になります。36 か月は実質月 495 円です。
  受け取りには、申込みから満 6 か月経過後の翌月 10 日頃に届く案内に沿った申請が必要です。申請時点で契約が終了していると対象外になります [30]
- **制約**: お試し期間中はメールアカウントの作成、サーバープログラムによるメール送受信、追加 FTP アカウントの作成が制限されます。
  FAQ は「など」と書いており、一覧は網羅的ではありません [2][3]。API のレート制限はスタンダードで 60 req/分・10,000 req/日・同時 5 で、
  超過時は 429 と `Retry-After` が返ります。API からサーバーを新規申込するにはプリペイド残高 20,000 円以上が要ります [5][6]
- **前提条件**: XServer アカウントで、「API キー管理」から対象サーバーを選んで API キー（`xs_` で始まる）を発行します。
  対象プランはスタンダード・プレミアム・ビジネスです。CLI（`xserver-cli`）と MCP サーバー（`xserver-mcp`）は npm で配布され、Node.js 18 以上で動きます。
  MCP からのサーバー新規申込は環境変数で明示的に許可しないと実行できません [5][7][8][9]
- **検証した内容**: 2026-09-05 に、お試し 2 日目のサーバーに対して実行しました。認証は `Authorization: Bearer <API キー>` です。
  結果は次のとおりです。

  | 操作 | 結果 |
  | --- | --- |
  | `GET /v1/me`、`GET /v1/server` | 200。契約は `plan_id: standard`、`status: active`。お試し中でも API キーの権限は `full` |
  | 読み取り 13 エンドポイント（サーバー情報・使用量・ドメイン・DNS・SSL・SSH・cron・FTP・DB・PHP・WordPress・ログ） | すべて 200 |
  | cron の追加 → 一覧 → 削除 | 200 / 200 / 200。追加 0.77 秒、削除 1.03 秒 |
  | SSH 公開鍵の登録 → 一覧 → 削除 | 200。登録すると「SSH 接続と国外アクセス制限を有効化」、最後の鍵を消すと自動で無効に戻る |
  | 初期ドメインへのサブドメイン追加 | **409**「初期ドメインにはサブドメインを追加することはできません」 |
  | メールアカウントの作成 | **409**「試用期間中のため、メールアカウントの追加はできません」 |
  | FTP アカウントの追加 | **409**「試用期間中のため FTP アカウントを追加できません」 |
  | `npx xserver-cli@1.4.0 --format json server info` | 環境変数 `XSERVER_API_KEY` と `XSERVER_SERVERNAME` だけで認証が通り、API と同じ JSON を返す |
  | `npx xserver-mcp@1.4.0 --services=server` に `tools/list` | ツール 118 個（cron・SSH 鍵・WordPress・メール・DNS・SSL・DB・バックアップなど） |

  お試し中の制限は公式の 3 項目のとおり API 側でも 409 で止まり、それ以外の設定は本契約と同じように通りました。
  検証で作った cron と SSH 鍵はその場で削除し、終了時に cron 0 件・鍵 0 件・SSH 無効を確認しています。
  API の実行ログは `GET /v1/logs` で呼び出しごとに残るため、AI に操作させた後の監査に使えます

### ロリポップ! スタンダード

2026-07-16 に公開 API と MCP サーバーの提供を始め、対象プラン（スタンダード以上）なら追加費用なしで使えます。
API の対象範囲はエックスサーバーより狭く、MySQL・cron・FTP は「近日公開」です。

- **料金体系**: スタンダードは 12 か月契約で月 957 円、36 か月で 605 円、1 か月契約で 1,265 円です。初期費用は無料です。
  ハイスピード（12 か月 1,045 円）以上は LiteSpeed になり、12 か月以上の契約で独自ドメインが 2 つ無料になります [10]
- **制約**: 公開 API は Personal Access Token（`lp_pat_` で始まる）による Bearer 認証で、`domains:read` や `wordpress:write` のようなスコープを
  発行時に選びます。レート制限はアカウント単位でスタンダード 120 req/分・20,000 req/日、日本時間 9:00 にリセットされます。
  対象外のプランで呼ぶと 403（`plan_not_allowed`）です [11][12]。お試し期間中はメール送信が 24 時間あたり 50 件までです [15]
- **前提条件**: PAT はユーザー専用ページで発行し、平文は発行時にしか表示されません。MCP サーバーは `https://lolipop.jp/api/v1/mcp` への
  HTTP 接続で、Claude Code なら `claude mcp add` に URL と Authorization ヘッダーを渡すだけです [12][13]。
  お試し期間中に PAT を発行できるかは公式ページに記載が無く、この記事では確認していません
- **検証した内容**: {{< verified spec >}}。公式の API ドキュメント（OpenAPI 3.1）で、エンドポイントが `/me`・`/domains`・`/subdomains`・`/php`・`/mail`・`/ssl`・`/wordpress`・`/server` の
  8 系統であることを確認しました [12]。別に配布されている「AI エージェント Skills」は、API ではなく SSH（`sshpass`）と Playwright によるブラウザ自動化で
  管理画面を操作する構成です。スタンダード以上が必要で、削除と WordPress は対象外です [16][17]

### さくらのレンタルサーバ スタンダード

12 か月契約の通常料金は 5 社で最も安く、14 日間の無料お試しにクレジットカード登録が要りません。
ただ、レンタルサーバ向けの公開 API は無く、AI に任せられるのは SSH 経由のファイル操作までです。

- **料金体系**: スタンダードは 12 か月一括で月 550 円、36 か月で 500 円、毎月払いで 660 円です。初期費用は無料です。
  ライト（12 か月 165 円）は SSH と cron が使えず、12 か月以上の一括払いのみです [18][19]
- **制約**: 公開 API はありません。さくらインターネットは VPS・クラウド・ウェブアクセラレータには API を出していますが、
  レンタルサーバにはありません [21]。SSH はスタンダード以上で、初期ドメインのアカウントに限られます。
  最低利用期間は利用開始日から 3 か月を経過した日が属する月末までで、その間は解約できません [19][20]
- **前提条件**: 会員登録だけで申し込めます。お試し中は独自ドメイン（クレジットカード払いを除く）・バックアップ&ステージング・コンテンツブーストが使えず、
  転送量とメール送信数に制限があります。クレジットカード払いはお試し中にキャンセルしなければ自動で本登録になり、
  銀行振込は初回請求を支払わなければ自動でキャンセルされます [19][20]
- **検証した内容**: {{< verified spec >}}。料金ページは JavaScript で描画されるため、ブラウザで料金表を取得しました [18]

### ConoHa WING ベーシック

時間課金の「通常料金」があり、最低利用期間なしで使えるのが他社と違う点です。
公式の自動化手段は AI エージェント向けの「サイト公開スキル」だけで、中身は FTPS でファイルを上げるツールです。

- **料金体系**: 通常料金はベーシックで 2.5 円/時、月上限 1,452 円です。WINGパックは 3〜36 か月の一括前払いで、
  2026-09-13 の確認時点では、12 か月契約で月 937 円、36 か月で月 678 円です。初期費用は無料です [22]。
  この価格は 2026-09-09 16:00〜2026-09-24 16:00 のキャンペーンで、ベーシックの 12・24・36 か月契約への新規申込み、または通常料金からの変更が対象です。
  適用は申込み時のみで、更新時の料金ではありません。税込の端数処理で表示価格と請求金額に差が出る場合があります [31]
- **制約**: 公開 API・CLI・MCP サーバーはありません。「サイト公開スキル」は `SKILL.md` と Python の FTPS ツール（`conoha-ftp.py`）の 2 ファイルで、
  一覧・ダウンロード・アップロード・フォルダの一括公開に対応します。削除・ディレクトリ同期・WordPress・データベース・SSH は対象外と明記されています [23][24]。
  WINGパックは契約期間中の途中解約ができません [22]
- **前提条件**: ConoHa アカウントと支払い方法（クレジットカード、または Amazon Pay・PayPal・銀行振込などで入金する ConoHa チャージ）です。
  無料お試しは無く、WINGパックは申込み月の料金が無料になります。スキルの利用には Python 3.8 以上と、公開フォルダに制限した FTP アカウントが要ります [22][24]
- **検証した内容**: {{< verified spec >}}。公式配布の `SKILL.md` を取得し、接続手段が FTPS で、書き込み先が対象ドメインの公開フォルダ配下に限定されることを確認しました [24]

### mixhost スタンダード

cPanel を採用する構成で、無料お試しの代わりに 30 日間の返金保証があります。
公開 API は無く、cPanel の `uapi` コマンドは SSH から使えますがサポート対象外です。

- **料金体系**: スタンダードは 12 か月契約で初回 968 円、更新後 1,518 円です。36 か月は初回 858 円・更新 1,298 円、
  3 か月は初回 1,188 円・更新 1,738 円で、1 か月契約はありません。「表示価格は初回料金に対してのみ有効で、通常料金で自動更新」と明記されています [25]
- **制約**: 公開 API・CLI・MCP サーバーはありません。SSH は公開鍵認証のみで root 権限は使えず、コマンドにも一部制限があります [27][28]。
  ヘルプは SSH 内で `uapi` コマンドを使う例を載せていますが、「コマンドの詳細なご利用方法はサポート対応外」です [29]
- **前提条件**: 支払い方法の登録が要ります。返金保証は初回申込みから 30 日以内で、解約手続きのうえサポートへ連絡する必要があります。
  ドメインやオプションは対象外で、銀行振込の場合は返金手数料 2,200 円がかかります [26]
- **検証した内容**: {{< verified spec >}}。料金ページ（`/price/`）はトップページに転送され、初回価格と更新価格が併記されていることを確認しました [25]

## 用途別の選び方

上から順に答えていくと、条件に合う対象にたどり着きます。各分岐の根拠は下の箇条書きと比較表の列に書いています。

{{< svg src="shared-hosting-japan-flow.svg" alt="用途別の判断フロー。DNS・cron・DB まで API で設定するならエックスサーバー、ドメイン〜WordPress までで月額を抑えるならロリポップ、カード登録なしで 2 週間試すならさくら、返金保証と cPanel でよいなら mixhost、ファイルを上げるだけなら ConoHa WING" caption="図: 用途別の判断フロー" >}}

- DNS・cron・SSH 鍵・データベースまで API や CLI から設定したい → エックスサーバー。「前提条件」列のとおり、REST API・CLI・MCP の 3 つを公式に出しているのは
  エックスサーバーだけで、お試し中でも API キーを発行できます。ただし「主な制約」列のとおり、お試し中はメールと FTP アカウントの作成が API でも 409 で止まります
- 操作したいのがドメイン・SSL・WordPress・メールまでで、月額を抑えたい → ロリポップ!。公開 API とリモート MCP が追加費用なしで使え、
  「料金」列のとおり 12 か月契約の通常料金はエックスサーバーより安くなります。MySQL・cron・FTP の API はまだ無い点に注意してください
- API は要らず、カード登録なしで 2 週間試したい → さくらのレンタルサーバ。「無料枠」列のとおりお試し期間が最も長く、12 か月契約の通常料金も最安です。
  ただし「主な制約」列のとおり最低利用期間が 3 か月あり、お試し中は独自ドメインが使えません
- AI にはファイルを上げてもらうだけでよく、時間課金で短期間だけ使いたい → ConoHa WING。通常料金なら最低利用期間が無く、
  公式の FTPS スキルで静的サイトの公開までは自動化できます。設定の変更は管理画面で行うことになります
- cPanel に慣れていて、お試しの代わりに返金保証で足りる → mixhost。「無料枠」列のとおり返金には解約手続きとサポート連絡が要り、
  「料金」列の初回価格は更新時に上がります

下は、この記事の対象のうち提携している 4 社の公式サイトへのリンクです。順位は上の箇条書きと同じで、
さくらのレンタルサーバは提携が無いためここには載せていません。

{{< ranking >}}
xserver: REST API・CLI・MCP の 3 つを公式に出している唯一の対象で、10 日間のお試し中でも API キーを発行して作成から削除まで通りました
lolipop: 公開 API とリモート MCP が追加費用なしで使え、12 か月契約の通常料金はエックスサーバーより安くなります。MySQL・cron・FTP の API はまだありません
conoha-wing: 時間課金の通常料金なら最低利用期間が無く、公式の FTPS スキルで静的サイトの公開まで自動化できます。設定変更は管理画面で行います
mixhost: 公式の自動化手段は無く cPanel で操作しますが、お試しの代わりに 30 日の返金保証があります。初回価格は更新時に上がります
{{< /ranking >}}

立てたサーバーの死活監視は、[死活監視の無料枠 5 つの比較](/posts/uptime-monitoring-free-tier/)で無料枠を比べています。
root 権限が要る用途なら、[国内 VPS の最小プラン比較](/posts/vps-japan-minimum-plan/)のほうが条件に合います。
