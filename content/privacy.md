## 取得する情報と利用目的

### アクセスログ

当サイトは Cloudflare のネットワークを通じて配信しています。配信のために、Cloudflare が IP アドレス・ブラウザの種類・アクセス日時・参照元などのログを取得することがあります。
これらは配信の安定化と不正アクセスの防止のために使われ、当サイトが個人を特定する目的で利用することはありません。
Cloudflare の取り扱いは [Cloudflare のプライバシーポリシー](https://www.cloudflare.com/privacypolicy/) に従います。

### 検索エンジン向けの計測

当サイトは Google Search Console を使い、検索結果での表示回数やクリック数を確認しています。
Search Console が当サイトに提供するのは集計されたデータのみで、個々の訪問者を識別する情報は含まれません。

### アクセス解析

当サイトは Cloudflare Web Analytics を使い、ページごとの表示回数・訪問数・参照元・表示速度を集計しています。
ページの表示時に Cloudflare の計測スクリプト（`static.cloudflareinsights.com/beacon.min.js`）が読み込まれ、閲覧したページの URL・参照元・国・端末やブラウザの種類・表示にかかった時間などが Cloudflare に送られます。
Cloudflare は、この計測に Cookie や localStorage を使わず、IP アドレスや User-Agent から個人を識別する処理（フィンガープリント）も行わないと説明しています（[Cloudflare Web Analytics](https://www.cloudflare.com/web-analytics/)）。
当サイトが見るのは集計された数字だけで、個々の訪問者を識別する情報は受け取りません。ほかの解析ツールを導入した場合は、ツール名と取得する情報をこのページに追記します。

## Cookie

当サイト自身は Cookie を発行していません。Cloudflare が配信のために技術的な Cookie を設定することがあります。
Cookie はブラウザの設定で無効にできますが、その場合も当サイトの閲覧に支障はありません。

## アフィリエイトプログラム

当サイトは、A8.net などのアフィリエイト・サービス・プロバイダ（ASP）が提供するプログラムに参加しています。
アフィリエイトリンクを含む記事には本文の先頭に **PR** と表示し、リンクには `rel="sponsored"` を付けています。

リンクをクリックすると、ASP が成果の計測のために Cookie を設定することがあります。
取得される情報と扱いは各 ASP のプライバシーポリシーに従い、当サイトはその情報を受け取りません。
掲載順・比較内容・結論は公式情報に基づいて決め、報酬の有無や金額では変えません
（[PR の方針](/about/#pr)）。
